# 当前原生界面视觉评审

产品：Android 上用于真实网页会话和多环境管理的工具。用户在手机上阅读、打开不同环境、选择和编辑网络。既定方向是 AdsPower 一类管理工具的清晰信息层级，适配手机，不追求桌面表格的原样缩小。需要少装饰、可读、紧凑，保留对象名称和判断所需信息。

只评审当前原生截图。逻辑视口有 360 × 640 dp、412 × 640 dp；font1 是系统默认字体，font2 是系统字体 200%。状态栏、导航栏和底部五项导航属于画面。环境和订阅为本地合成记录；未连接和未配置网络是真实当前状态，不把它们视作制作说明。会话截图只评原生外壳，不评未登录的官方网页。

既定规范：系统中文字体与现有线条图标；浅灰蓝背景、白色内容区域；主蓝 #2468f2，深色正文 #172033，灰色辅助文字 #64748b。蓝色表达主要动作或选中，真实网络状态同时用颜色和文字表达。环境名称约 16–17 sp，正文与操作 13–15 sp，辅助信息 12–13 sp，页面标题可更大。卡片圆角 14 dp，按钮/输入框 12 dp，居中弹窗 18 dp；列表、表单和弹窗的通用按钮触摸高度为 48 dp；会话头部保留紧凑的 44 dp 第一行和 28 dp 整行网络入口。普通字号底部导航约 60 dp。大字体下允许滚动和重新排列，不能为塞入信息而缩小字体。

不可改变：品牌、字体、主色、五项导航（会话/环境/下载/网络/设置）、真实状态含义、环境名称、独立环境与网络管理逻辑。不得替换官方网页、改官方消息/输入/模型 UI；不能以本地 HTML 冒充网页。此轮只精修既有 UI，不新增功能，不改导航结构。
