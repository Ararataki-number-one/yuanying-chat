## 细节与取舍

- 下拉项的默认纯黑字色与共享正文色不一致：显示方式、隐私等级使用共享适配器，统一字色和字号，保留原选项与位置映射。
- 全屏环境编辑页的状态栏原先受背景遮罩影响：去掉此全屏窗口的背景变暗，并明确状态栏颜色和深色图标；居中网络弹窗仍保留原遮罩。
- 删除“网络 ·”重复前缀和没有使用记录时的“尚未使用”，保留有实际时间的最近使用信息。
- 保留“地区来自名称”。它区分节点名称推断与真实出口核验，是用户判断需要的信息，不能因节省空间而删除。
- 评审图片里小按钮的可见背景约 36 dp；静态图不能证明其点击范围。核对控件树与布局后确认列表按钮仍为 48 dp 触摸高度，内缩只影响背景。节点复选控件的高度问题则已修正。
- 水平筛选列表保留既有滚动方式，并增加边缘渐隐提示。没有增加统计面板、导航项目或新业务入口。

## 主执行者修正后核对

再次看图发现系统大字体会放大刷新字形并裁切；将网络刷新图标固定为 24 dp，保留文字跟随系统字体缩放。对两个宽度，环境列表首张卡片由屏幕 y=239 dp 上移至 y=210 dp，卡片高度从 146 dp 改为 140 dp。大字体下当前入口“日本大阪 03”可完整显示，两个代理格式可换行读取，节点行保持 48 dp 触摸范围。短屏大字体下弹窗内容和节点列表仍需滚动，底部确认与保存按钮独立可见；这是适应字号的布局，没有缩小用户选择的字体。

## 验证边界

静态截图不能证明完整键盘流程、动效、真实账号长期登录或真实出口可用性。会话取证只验证真实原生外壳与未配置网络状态，不用本地 HTML 冒充官方聊天网页。既有自动化操作回归另见版本验证首页，不能替代真实账号与 ARM 手机验收。
