## 改进

- 环境卡片突出名称、分组、网络状态和最近使用。“打开环境”为主要操作，编辑和配置收进“更多”。
- 支持长按 / 多选、全选当前结果、批量分组、收藏和取消收藏；明确提示筛选外选择范围。
- 批量写入采用事务，只更新已选且已创建环境，保留备注、草稿与网络配置。
