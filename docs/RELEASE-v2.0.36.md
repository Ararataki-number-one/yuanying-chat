# 2.0.36（条件开发候选）

已有回复全文预热任务执行前，增加一次提问节点归属检查：原提问必须仍连接在当前文档中，且其后不能出现新提问。过期预热不再读取和转换旧回复正文；正常回复、在前面补入旧历史以及无关侧栏变化继续按已有逻辑处理。

保留原 URL、回复与正文节点、范围及内容修订检查，以及交互调度、缓存、消息锚点和阅读位置恢复机制。不发送、重发聊天，也不移动视口。有效长回复仍在单个回调中同步转换，本次未增加按 CPU 时间预算切片。

受控 DOM 的同输入配对只比较正文读取、转换计数和最终内容，不能代表总拓扑检查成本、CPU、手机帧率或整体提速。原生任务在 DOM 不变时被替换、编辑同一提问和同提问重新生成等情况，没有增加新的预热判断。
