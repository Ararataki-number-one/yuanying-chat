# 2.0.19：阅读位置稳定性

versionCode 72，基于 2.0.18，保留单 GeckoView 与 ChatGPT 原网页。

- 触摸、滚轮和滚动键操作会使旧的网页恢复任务失效，执行前再次校验文档、页面状态和阅读交互。
- 开始触摸时取消旧的缩放对齐、阅读恢复与键盘辅助任务；拖动期间停止这些辅助滚动，保留正常点击后的输入行为。
- 阅读恢复优先使用消息和可见段落锚点。补入历史、图片改变高度后按原消息计算偏移；浏览器已保持位置时不再写入。原消息消失、匹配不唯一或变换不支持时保留当前视口。

固定离线流程已复现并验证跳位缺口；主线程扫描候选未得到稳定收益，已撤销，没有纳入本版。不能据此声称手机帧率或真实代理线路延迟改善。详细对照见 [阅读稳定性报告](READING-STABILITY-20261025.md)。

正式打包前须通过当前同源码的发布检查。离线浏览器、主机检查、受控 Android 回归与手机实际使用分别记录；真实 ChatGPT、百度输入法和手机 Gecko 滑动帧耗时仍需现场验证。
