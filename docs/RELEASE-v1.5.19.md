# 1.5.19

- 应用内后续更新下载支持暂停、继续和断点续传。网络中断或系统暂停任务时保留已下载部分，恢复后继续；显示实时速度和预计剩余时间。
- 减少原网页模式输入、滚动和长回复生成时的重复网页扫描，把浏览器状态保存放到后台，降低操作被后台任务打断的机会。
- 聊天繁忙时推迟自动测速和地区查询，避免重复探测当前线路。手动测速仍可使用。
- 出口核验服务突然断开时，保持已核验且未改变的线路，避免误中断网页。

使用原签名，支持覆盖安装和自动更新。保留真实网页、登录数据、环境隔离和固定出口保护。下载完成后仍核验完整文件与签名。

本次升级仍需先下载并安装；续传对安装本版后的应用内更新生效。实际网速仍受手机网络或 VPN、入口、固定出口和下载服务器影响。
