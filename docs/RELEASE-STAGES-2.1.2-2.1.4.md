# 本次更新的正式版发布顺序

本次更新分为三个可独立安装的正式版，依次发布。每版沿用现有 Android 签名及包名，版本代码递增，默认网站继续为 ChatGPT。各版的实际发布时间、安装包与验收结果以对应 GitHub Release 为准。

| 正式版 | 版本代码 | 本阶段交付范围 |
| --- | --- | --- |
| 2.1.2 | 104 | Worker 请求身份与创建限制、Gecko 每环境原生时区、默认跟随出口 IP，以及相关会话等待与失败恢复修复 |
| 2.1.3 | 105 | 在 2.1.2 基础上增加现有 Gecko 内核真实支持的 CPU 可控项及其冷启动确认 |
| 2.1.4 | 106 | 在前版基础上增加 Gecko TLS 协议控制，并单独验证实际连接结果 |

2.1.2 的生产源码不包含后两版的 CPU、TLS 配置实现。每个正式版均须完成其完整回归及原签名安装包核验后再发布，后续版本不能抢先覆盖前版的稳定更新入口。

Chromium 仍为 Android System WebView；各内核仅交付实际支持的配置。Worker 限制不等于 Worker 内部指纹伪装，Gecko 的 Service Worker 时区隔离仍有边界。TLS 协议控制也不代表任意 JA3、JA4、HTTP/2 或 HTTP/3 指纹定制。
