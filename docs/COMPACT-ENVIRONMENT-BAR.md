# Safari 风格环境栏（2.0.3）

按用户的截图要求，聊天页默认保留居中的小环境栏，以当前环境名称替代网址。普通字号下收起高度为 28 dp，大字体按文字高度扩展，触摸探索开启时至少 48 dp。

- 网络信息始终显示；点击小栏展开原有环境工具栏；展开后的名称居中，仍可点击切换环境。
- 向上滑动顶部或聊天网页，在手指离开后收起为小栏。
- 普通向下阅读保持收起，防止工具栏反复展开；底部“会话”按钮保留主动展开入口。
- 回到应用保留当前状态。进入原生下载、网络或设置页不显示聊天环境栏。
- 收起时清除展开按钮的扩大触摸区域，防止小栏误触菜单或环境切换。
- 不修改官方网页、Gecko 会话、网络连接、登录与草稿逻辑。

代码位置：`DesignChrome.java` 管理两种布局、名称与手势；`AppHub.java` 管理聊天页的小栏可见性。

回归用例更新于 `tests/gecko/ChromeCollapseIntegration.java`、`tests/gecko/run_chrome_collapse.py` 与 `tools/gecko/chrome_collapse_contract.py`。覆盖小栏点击、上下滑、原生顶部滑动、页面返回、前后台恢复，以及文档、Cookie、草稿、任务和会话不变。Android 用例需要重新构建并在设备上执行，不能复用 2.0.2 已发布包的测试结果。
