# 2.0.3：小环境栏与常显网络信息

聊天页顶部默认显示居中的小环境栏，以当前环境名称替代网址。点击小栏展开菜单和环境工具栏，向上滑动顶部或网页后收起；向下阅读不反复展开。

网络地区、IP、延迟和连接状态始终保留在小栏下方，继续使用当前环境的真实网络状态，保持只读。

大字号按文字高度适配。收起时移除展开按钮的触摸扩展区域，避免误开菜单。环境栏调整不主动刷新网页，不更换 Gecko 会话，不修改登录、草稿或网络连接。

关闭网页双击缩放，减少快速点击定位光标时与缩放手势识别的冲突；双指缩放和菜单缩放继续保留。

沿用原包名和签名，支持覆盖安装。本次按用户发布指令提供正式版；云端受控验证与 ARM 真机验收分开记录，尚无本版本真机验收结果。发布资产附带构建、回归和签名记录。
