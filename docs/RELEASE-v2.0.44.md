# 2.0.44：后台执行环境覆盖说明

本版功能原以 2.0.31 为开发基线；当前已离线集成到 2.0.43 的顺序源码前缀，完整 APK 构建、正式版本验收与发布仍待完成。

本轮把 Shared Worker、Service Worker 的检测边界放到请求结果、高级说明和服务摘要中：客户端目前未检查它们的真实请求、缓存和生命周期，也没有注册或清理站点 Worker。Dedicated Worker 的既有对照继续保留。

检测服务可以在能力响应顶层用可选的 `backgroundCoverage` 声明自己是否提供两类检测。旧服务不含字段时显示“未知”；服务声明支持，只作为服务自述。客户端始终显示“尚未覆盖”，不会据服务就绪、接口存在或自报 `true` 判定保护已验证。

服务仍只处理原有六类协议地址。没有新增 Shared Worker 或 Service Worker 脚本端点，没有扩展网页请求权限，也没有增加轮询、注册或清理操作。

验证使用实际 Java 模型与两个 JSON 运行库、受控会话边界，以及带受信测试证书的本机 HTTPS 服务；保留既有请求身份、语言、iframe、服务检查和回复读取测试。另用服务声明升级为观测、字符串布尔强制转换两种错误实现，确认检查能够拒绝误判。

这些检查不证明 ChatGPT 当前使用了哪些 Worker，不证明手机内核的对应接口可用，也不证明真实设备上的保护效果。完整 APK、顺序升级和真实手机验收仍需后续执行。本版没有新增 Shared Worker／Service Worker 探针。
