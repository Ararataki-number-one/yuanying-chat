## 十项已实现的工作流程

| 轮次 | 功能与入口 | 实际变化 |
| --- | --- | --- |
| 1 | 下载中心 → 搜索 | 按文件名、类型或环境关键词检索全部下载记录，先检索再分页；支持多个关键词。 |
| 2 | 下载中心 → 环境、类型与排序 | 组合筛选所属环境与文件类型，提供时间、文件名、大文件优先等排序；记住工作范围，区分历史环境及归属待确认记录。 |
| 3 | 下载中心 → 收集文件／收集篮 | 跨页和筛选保留最多 30 个已保存文件，一次调用系统分享；支持移除、清空、加入本页与明确的容量反馈。分享前核对实际发布记录及可读性。 |
| 4 | 环境管理 → 全部环境任务 | 汇总连接问题、环境配置草稿和新鲜的等待回复状态，直接进入对应环境排查、继续编辑或回到原会话。配置草稿与聊天输入明确区分。 |
| 5 | 环境管理 → 工作视图 | 命名保存、恢复和删除最多 8 组搜索、分组、状态、排序条件；离开后记住当前范围。恢复视图会清除多选，避免隐藏选择误操作。 |
| 6 | 会话环境名称／环境管理 → 快速切换 | 搜索环境并按最近使用排序；切换前核对槽位、环境 ID 和代数，继续原会话。普通“打开环境”继续保留原有概览流程。 |
| 7 | 会话选项 → 草稿救援 | 搜索当前环境的本机恢复副本，预览并复制；可主动暂存当前网页输入。遵守本机草稿保存开关及策略版本，复制后由用户手动粘贴。 |
| 8 | 会话选项 → 离线会话检索 | 搜索已在本机保存的对话标题和消息全文，分页阅读、查找与复制消息或整段对话；长文本检索在后台执行。仅覆盖此环境实际保存过的文字。 |
| 9 | 会话选项／环境管理／设置 → 搜索操作，或 Ctrl+K | 使用“草稿”“账号”“文件”“网络”等关键词直接找到操作，支持别名、组合词和最近使用排序；保留原有重新加载保护。 |
| 10 | 会话选项／搜索操作 → 进入专注阅读 | 收起应用工具栏和导航，扩大原网页阅读空间；48dp 退出按钮、返回键或 Esc 可恢复。保留模式状态；登录、空白加载及自检页面自动显示必需工具。 |

本次不增加聊天发送路径。快速切换、检索和阅读均沿用当前隔离环境；本机草稿和历史使用原有存储，不引入额外加密保证。多文件分享只在用户点击后调用系统选择器。

## 验证与构建边界

新增行为检查执行真实生产策略、存储适配器或提取的生产方法；需要 Android 的边界在主机测试中明确使用替身。覆盖全库搜索再分页、精确环境身份、保存视图、跨页收集、文件发布变化、草稿策略、长文本复制、过期回调以及专注布局。JSON 相关新流程在桌面和 Android 兼容的 JSON 实现中分别执行。

修改过的生产 Java 文件同时通过真实 Android SDK 37.1 API 编译检查；周边应用边界由当前源码签名生成、使用明确的编译替身。该检查不等于完整应用或 Gecko SDK 编译。现有下载恢复、聊天下载进度、网页恢复与顶部工具栏回归也运行验证。

可通过统一入口复跑（依赖路径按本机调整）：

```bash
python3 tests/run_ux_ten_rounds.py \
  --java-home /path/to/jdk17 \
  --json-jar /path/to/json-20240303.jar \
  --android-json-jar /path/to/android-json.jar \
  --android-jar /path/to/android-37.1/android.jar
```

Gradle 清单生成和浏览器扩展版本核验通过。完整 APK 构建仍需要基线规定的官方 Gecko 输入与派生 SDK；当前云环境对 `maven.mozilla.org` 的请求返回代理 403，已找到的准确 CI 构建输入包超过连接器下载大小上限。因此本次交付源码、补丁及验证记录，未交付安装 APK，未完成 Android 设备或真实账号验收。

完整构建仍遵循 [BUILD.md](BUILD.md) 的内核来源核验、派生 SDK 准备及签名流程。
