# 元婴期院士 1.5.9

修复电脑版网页最低只能到 100% 的限制，支持缩小到 60%；保留官方真实网页，缩放时不刷新页面。每个环境独立记住缩放选择。

补齐独立环境进程的 AndroidX 前后台生命周期初始化。网页进程被系统回收时，优先恢复同一环境的 SDK 页面状态，包括历史、滚动和表单；连续恢复失败时保留手动重试，不自动重新发送消息。

会话 Cookie 保存于每个环境私有的浏览器扩展存储，重启时通过官方 Cookie API 恢复。保留 Cookie 原有属性；网站删除 Cookie、用户退出登录和清理环境均更新保存记录。不会修改服务器登录有效期。

构建和 Android 回归验证见随版本发布的验证记录。受控测试使用模拟 Cookie，不包含用户账号。Google／ChatGPT 真实账号登录及使用中的服务器侧会话失效，仍需在实际手机上核验。

安装包使用原签名，可覆盖安装，不需要卸载。
