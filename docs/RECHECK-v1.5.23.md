# 基于 1.5.23 的候选复查

基线：v1.5.23-gecko / 6a1bab77f1bcc70f0fc4f990b287fec08ec54412，正式 versionCode49。候选为 1.6.0/code50、1.7.0/code51、2.0.0/code52，按顺序审查与合并；本交付没有合并 main 或发布 APK。

## 保留的新版本能力

保留已发布的独立入口/出口订阅、刷新令牌、实际连接节点身份、不可变加密来源与活动快照、pending 安全应用、取消与回滚、线路 lineage、SealedFileIo 并发保护，以及手机自适应缩放、键盘焦点滚动、草稿和登录目录。旧候选的自定义出口解析器不再移植。

## 已修复的可复现问题

| 阶段 | 触发与影响 | 修复 |
|---|---|---|
| 1.6 | 手工出口 A 改成 B 后重新添加 A，历史别名错误命中 B | 按当前端点/凭据精确去重，历史 ID 占用时生成独立 ID |
| 1.6 | 较新或结构损坏的目录被归一化为空并改写 | 严格格式读门，不支持的格式只读并保留原密文；合法旧格式迁移 |
| 1.6 | 检测器故障误报已核验原线路不可用；gstatic 或 TLS 协议错误导致无依据的恢复 | 三态准入；空闲时经原受保护线路交叉检查；只有明确传输故障累积为恢复依据 |
| 1.6 | 旧 entryMode 为空导致迁移失败；失败候选已清除而 desired 网络仍指向它 | 保留旧自动选择含义；清除/取消候选后同步已保存线路 |
| 1.7 | Activity 结束后模板已保存却未发布至保留会话 | 发布准确缓存与队列，再处理 Activity 生命周期，唤醒后台应用 |
| 1.7 | 父编辑页旧控件覆盖新模板；重复保存“保持语言”回退旧语言 | 同步父控件/基线；每次读取最新期望语言 |
| 1.7 | 无变化保存重载健康网页，或主线程做 no-op 核验 IPC | 只跳过完整准确的已应用状态；后台核验与 UI 代次/回执复核 |
| 2.0 | 网站直接发起的回复在后台无法观测结束，持续活跃 | 活跃与同步使用同一有效当前回复条件；新 idle 观测允许暂停 |
| 2.0 | 导出混入旧文件；旧测试 APK 报告被误标成新源码 | 全新暂存及文件白名单；integration 构建嵌入源码版本，核对已安装 APK 哈希 |

## 验证边界

已执行生产模型、目录、来源/快照、lineage、加密文件租约、线路健康、模板控制器/界面、扩展桥及资源决策的主机回归，并完成各阶段 Java 源码及 Android 夹具的接口签名编译。签名编译用临时 Android API35 和已发布 GeckoView157 接口类，不等同官方 AAR 完整构建。

新增只读 PR 工作流分别运行主机检查、固定官方 SDK 的 release/integration APK 编译与 lint；CI 的具体执行状态应在对应 PR 查看。Android 新夹具已补充，不宣称已在本轮执行。真实 ARM、Keystore、ChatGPT/Google 登录、跨上下文指纹、耗电和公网延迟还需设备验收。原网页自行开始的上传尚没有完整原生状态观测，现有附件记录不足以证明全部后台上传已受保护，此项仍需补齐及单独验证。源码修复不证明 413ms 或 3416ms 会下降多少。

官方 GeckoView 是唯一内核。独立时区、Canvas/WebGL/Audio/字体的自定义原生控制仍未实现；能力清单准确显示不支持，不能把这些候选称为深层指纹控制已全部完成。

## 合并建议

使用新审查包替换基于 1.5.21 的旧包，先审查 1.6 再 1.7 与 2.0。所有 PR 仍为草稿；main 比正式发布标签旧，PR1 会包含已发布版本的历史，请核对基线后再合并。完整验收见 MERGE-AND-ACCEPTANCE.md。后续正式版本若使用了新的 versionCode，发布候选前继续递增。
