# 2.0.12：修复整条线路分享的入口参数兼容性

- 补齐分享导出对当前内核已支持的 VLESS encryption、XUDP、packet-addr、smux 及旧式 WebSocket 请求头等连接参数的支持。完整保留参数，继续使用实际内核重解析并比较节点指纹。
- 修复旧手工出口没有显示名称时无法分享的问题，使用服务器地址作为名称。
- 分享失败时区分不支持的参数、缓存不可读取、线路已变化、内核解析失败与节点身份不一致，不再只显示同一个笼统提示。错误提示不输出账号、密码或原始内核错误。
- 保留单独分享入口、出口与整条线路；导入仍须先预览再选择环境。分享不改变原线路或 ChatGPT 登录数据。

新增主机回归覆盖完整参数往返与不支持字段拒绝；Android 回归从生产“分享整条线路”读取活动快照、执行内核身份校验，再通过实际界面导入 VLESS 与固定出口。旧版导出器在相同受控 VLESS 配置上可复现失败。

受控配置不包含用户订阅和凭据。用户实际订阅与 ARM 真机尚未验收；本版修复已复现的兼容性缺口，不能据此断言截图中的节点只有这一种失败原因。沿用原签名，可覆盖安装。
