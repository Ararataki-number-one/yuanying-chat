# 阅读稳定性修复与测量记录

基线为已发布的 2.0.18，源码 `04f6375c889b059afad57ff4fd8eb180cc2341b0`。本次为开发分支修复，尚未发布新的 APK。保留单 GeckoView、原网页、环境隔离与固定出口。

## 已保留的修复

| 场景 | 修复前的实际结果 | 修复后的实际结果 | 验证范围 |
| --- | --- | --- | --- |
| 恢复开始前已按住并拖动网页 | 后续真实 touchmove/scroll 未取消恢复，80 ms 后回到旧位置 | 文档起始记录真实交互；活动触摸、滚轮、滚动键和惯性阶段使旧恢复失效 | 离线 Chromium 真实输入 |
| 同地址的新导航、离开后返回 | 旧延迟任务仍可能写入位置 | 执行前再次校验文档、导航代次和生命周期 | 受控生命周期与导航场景 |
| 适应屏幕后立即单指拖动 | 旧 fitY=320 覆盖用户新位置 900；旧队列还能重新启动缩放 | DOWN 取消旧对齐、位置和焦点任务；拖动中的布局不重新授予旧请求 | 完整原生控制器的 JVM 测试，非 APZ 实机 |
| 键盘已显示后拖动 | 后续布局变化重新安排焦点显露 | 拖动与取消后抑制旧请求；完整点击后允许新的有效布局请求，UP 本身不强制拉回输入框 | 同上 |
| 上方补入历史、图片高度变化 | 同一像素指向另一段文字 | 使用稳定消息标识、可见段落路径及屏幕内偏移；按当前几何校正 | 离线 Chromium 实际布局 |
| 浏览器已保持位置 | 再次写入旧像素 | 位移在容差内不重复滚动 | 同上 |
| 原消息消失、ID 重复或段落有歧义 | 可能恢复到旧像素对应的其它内容 | 不猜测目标，保留当前视口 | 同上 |

锚点读取不修改网页消息或样式。内部节点身份使用 WeakMap；段落探测、路径深度和新 DOM 的匹配范围均有上限。普通轴向 CSS 缩放会换算坐标；不支持的倾斜、旋转与透视变换保守地放弃恢复。未知旧快照仅在内容和滚动尺寸均匹配时允许兼容像素恢复。

## 对照与回归

- 11 个阅读恢复场景：原 2.0.18 有 6 个失败，修复后全部通过。真实输入与受控生命周期场景分别标注。
- 14 个锚点布局场景：在仅完成交互保护的 `d2ae133` 上有 12 个失败，锚点修复后全部通过。
- 原生控制器原 71 项断言及顺序保留，加 22 项交互控制，共 93 项通过；另外独立验证了导航代次变化和 CANCEL 边界。
- 浏览器 runtime 测试运行器报告 46 项通过；原网页操作、草稿恢复、资源观察及两个滚动阶段检查通过。原草稿恢复的 27 项断言不变，测试现在先取得真实滚动尺寸与位置的快照。
- 独立审查发现并修正了嵌套消息别名、重复段落和非轴 CSS 变换的反例。失败原件保留，不以较晚成功覆盖。

可在仓库根目录复跑：

```sh
node tests/browser-runtime/reading-restoration-chromium.cjs
node tests/browser-runtime/reading-anchor-chromium.cjs
node --test --test-concurrency=1 tests/browser-runtime/*.test.cjs
```

Chromium 脚本需要 Playwright Core 和 Chromium；可用 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH` 指定本地安装。DOM 回归使用 `JSDOM_MODULE` 指定 jsdom。

## 性能试验及回退

固定离线流程包含 480 条历史消息、126000 字符的当前回复、16 次真实滚轮输入和 16 次回复追加。每个版本运行三轮正常测量，CPU 采样另跑一轮，不混入正常结果。这是阅读专项微基准，与此前下载历史的正式 A3 流程分开。

原基线三轮帧间隔 p95 为 16.7 / 16.7 / 16.8 ms，没有记录超过 32 ms 的帧间隔或超过 50 ms 的长任务。因此此环境未复现手机所述的明显卡顿。

只试验了一个性能候选：为官方停止按钮增加正向快速检查，保留原有兼容回退。结果没有达到预先规定的稳定改善条件，已经撤销，未合入阅读修复分支。

| 同一流程实际耗时 | 基线三轮 / ms | 候选三轮 / ms |
| --- | --- | --- |
| 13 次核心驱动调用合计 | 36.3 / 47.9 / 47.2 | 47.4 / 47.8 / 33.4 |
| 生成中 4 次驱动调用合计 | 9.1 / 22.6 / 20.6 | 20.4 / 19.4 / 6.9 |

候选还增加了部分空检查的开销。不能用扫描候选数下降或最快一轮替代实际收益。候选 `b248503` 与撤销 `7b7c57a`、三轮数据、独立 CPU 样本和回退理由均保留。

## 尚待验证

离线 Chromium 与控制器测试不等于 Android Gecko/APZ 或手机帧耗时验证。本次没有真机提速结论，也没有声称所有网页卡顿均已解决。下一步应在同一手机、同一长聊天与同一操作顺序测量拖动、加载历史、回复完成和键盘开关，保留原始帧间隔与长任务，再决定是否调整扫描或长文本采集。

本地完整原件位于 `work/plan-repairs/reading-20261025/`，包括三组独立审查、失败复现、修复后结果及已撤销性能候选的数据。
