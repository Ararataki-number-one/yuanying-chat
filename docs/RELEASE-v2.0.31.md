# 2.0.31（84）：环境删除与登录数据清理

本版在已发布的 2.0.30 基础上处理环境删除、重建与登录重置的归属边界，不重复实现已有 Cookie 保存和退出登录快照。

- 删除确认绑定用户打开弹窗时的环境 UUID 和代次；环境变化后，旧确认不能删除当前槽位的新环境。
- 删除任务携带对应身份，清理完成时再次核对；过期任务不继续处理新环境。
- 删除和登录重置共用按槽位的维护锁，避免两个清理任务交错执行。等待旧进程停止时不持有目录数据库事务。
- 默认环境删除及登录重置同时清理真实的加密自检记录，避免重新创建后沿用旧报告；共享订阅与用户已保存的下载文件保留。

## 验证与范围

正式版已发布，版本为 **2.0.31 / 84**，使用原证书签名，可覆盖升级。完整受控 CI、原十项发布校验与公开安装包核对通过。

主机文件锁和故障控制用于验证具体竞态，不替代真实手机上的 GPT 登录、退出登录、百度输入法及网页存储验收。继续沿用 Gecko、Cookie、存储隔离与网络保护机制，不自动直连、改变固定出口、重发聊天或迁移登录态。
