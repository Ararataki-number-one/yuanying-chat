# 原生运行配置与验证范围

浏览器继续沿用当前 GeckoView 原生进程与存储策略。查看“环境 → 模板说明与状态详情”只读取已有运行实例；不会创建浏览器、重载聊天、改变保护等级或访问检测网站。

本地自检同时保存当时的原生运行配置摘要，绑定环境、代次与已应用配置版本。运行实例、已应用配置或原有网页／线路身份发生变化时，本次结果保持过期状态。记录沿用现有本地加密保存机制。

| 显示内容 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 隔离渲染请求 | Android 10 及以上请求 SDK 使用隔离渲染进程；旧系统没有该请求 | 请求本身不能验证实际子进程 UID 或完整沙箱 |
| SDK 设置对象的隔离进程值 | 当前运行实例的公开设置 getter 返回值 | 不是操作系统进程采样 |
| Fission 与网页隔离策略 | 当前 SDK 设置对象中的显式值；空值显示“沿用 SDK 默认，实际值未观测” | 空值不等于已关闭，也不能据此声明跨站进程已隔离 |
| Cookie 策略与自选分区选项 | 当前 SDK 返回的配置值，保留策略数字和布尔值 | 单个自选分区选项的 false 不代表所有存储分区都关闭；配置值不替代跨站存储检查 |
| 未取得 | 运行实例不存在、已停用／删除，或对应 getter 不可用 | 不会补成已开启或已验证 |

没有采集的进程 UID、跨站进程、存储分区与完整沙箱，分别记录为 `not-collected`。对应 `*Verified: false` 表示没有取得验证证据，不表示已经实测保护失败。异常只保留固定的“未取得”状态，不导出异常消息、URL 或文件路径。界面没有新增 Fission、沙箱或存储策略开关。

## 当前 SDK 依据

发布链固定使用 `org.mozilla.geckoview:geckoview:157.0.20261005135250` 的派生输入同步 SDK；输入版本、上游修订与不可变校验值见 `third-party/sdk/`。当前派生修改仅替换输入同步类，不把本次设置观测当作新增安全内核。

已检查正式版 2.0.31 原签名 ARM64 APK 的清单与实际 DEX：包含非公开的隔离子服务声明，公开 SDK 提供上述 getter；Fission 与网页隔离策略 getter 的返回类型允许为空。本次保留 SDK 默认行为。

此前同一 2.0.31 源码构建的受控 Android x86_64 诊断日志，曾观察到 `isolatedTab` 子服务使用不同于应用进程的隔离 UID，并出现 `isolated_app` 的 SELinux 拒绝记录。这是该次受控环境的运行证据，不代表所有网站、手机、子进程、跨站隔离或全部沙箱机制已经验证，也不能代替后续版本自己的构建与运行检查。

## 发布前及设备上的剩余验证

相关主机检查执行真实生产读取和过期判定方法，但 SDK／Android 边界使用受控适配器。它们验证空值、异常、环境归属与过期处理；不验证 Gecko 或操作系统安全效果。

正式发布仍需实际 SDK 编译及既有 Android 验收。在真实手机上，还需记录渲染进程与 UID、跨站导航和登录跳转、状态分区及兼容性。普通多进程、一次设置回读和一次登录成功，均不作为完整沙箱证明。
