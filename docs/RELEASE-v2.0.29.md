# 2.0.29：独立参照的总览与失配原因（交接候选）

2.0.25 已有四类独立参照、旧主页面格式迁移、原子保存失败回滚及按类清除。本版在其上增量完善：

- 固定参照页显示四类参照的保留情况，所选执行环境仍通过原有当前页面、配置和跨源来源检查后才允许固定或比较。
- Worker／iframe 条件失配时列出具体字段，不将不同来源、配置、应用／内核或探针版本当成同组结果。
- 新增结构化 overview，明确调用方仍需验证实时文档；UI 总览仅说明保留情况，不借过期报告声称当前可比较。
- 数据格式、八条历史上限和各类参照独立保存规则不变，不增加自动采样或网络请求。

新增联合主机回归覆盖人工进度和参照状态，原双报告及四类参照回归保持。真实设备的持久化失败与 GPT 页面兼容仍需交接验收。
