# 2.1.7 · 小号环境胶囊与玻璃浏览器导航

版本 `2.1.7`，版本代码 `109`，在正式版 `2.1.6 / 108` 的源码上继续维护。正式安装包与发布状态以 [GitHub Release](https://github.com/Ararataki-number-one/yuanying-chat/releases/latest) 为准。

## 顶部更紧凑

环境胶囊改为小号样式，收紧上方留白，显示当前环境名称。点击胶囊直接切换环境；网址输入统一从底部网址框进入。可见胶囊缩小的同时，保留独立的触摸范围和系统安全区；大字体时按文字实际高度适配。

当前环境的网络信息回到胶囊下方。网络状态使用当前环境实际可用的数据；尚未测量、数据过期或未连接时保留相应提示。滑动收起浏览器顶部时隐藏网络信息行，保留环境切换入口。

## 保留原有玻璃外观，调整五个入口

底部继续使用原有的四个独立圆形玻璃按钮，以及中间的长圆角网址框，保留现有玻璃渲染、高光和阴影。五个入口从左到右为：

| 入口 | 功能 |
| --- | --- |
| 主页 | 返回当前环境的主页。 |
| 网页窗口 | 查看当前环境实际打开的网页窗口。Chromium 使用已有标签页管理；Gecko 展示现有主页面和仍然有效的弹出页面。 |
| 网址／搜索 | 查看并编辑当前网址，或输入搜索内容。 |
| 网页工具 | 后退、前进、刷新／停止、复制网址等当前网页操作；专注阅读、分享、页内查找等按内核已有能力提供。 |
| 浏览器菜单 | 环境管理、网络管理、下载及应用设置等入口。 |

顶部胶囊负责环境切换，第二个底部按钮负责当前环境中的网页窗口。Gecko 的窗口入口复用现有页面会话，不把其他环境或已关闭页面计为可切换窗口。

底栏继续处理键盘出现、阅读模式、横竖屏、窄窗口和大字体；操作控件保留至少 48 dp 的命中范围。网络和下载等管理页面保留各自导航。

“网络情况”弹窗的关闭按钮固定在底部；测延迟和连接详情放在可滚动的正文中，避免大字体下关闭按钮被挤出可见区域。

## 照片上传与维护

保留 2.1.6 的照片上传内容修复：原始文件复制保持原字节，受支持的网页图片解码、Canvas 转绘及重新编码继续保留照片内容。临时许可仍按原有来源、文档和会话生命周期管理，不改变此前公布的隔离边界。

本次将网页工具与管理菜单分开组织，两种内核继续复用底栏布局。环境切换、网页窗口选择和地址编辑通过各自已有业务路径执行，保留页面归属、过期回调和关闭会话检查。

## 发布验证

新界面使用独立的导航验收契约 v4，检查顶部点击动作、网络信息位置、五个底部入口、网页工具、地址输入及页面往返。历史 v3 证据继续保留原来的语义，不能代替 2.1.7 的验收。

发布继续要求完整构建、lint、原有浏览器与网络回归、照片像素验证、Android 界面和原签名核对。自动验收的源码、安装包及运行身份必须一致。受控 Android 与网页样本的结果不表示实体手机、个人线路、真实账号或所有网站已逐一验证。
