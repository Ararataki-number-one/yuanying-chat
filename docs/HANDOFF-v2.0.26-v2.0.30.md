## 历史交接包的导入方式

以下命令只适用于尚未整合这五份增量的旧基线；当前已经逐版整合的源码不得重复应用。先保留自己的未提交修改，在独立分支操作。基线已存在时，可按编号应用交接包中的五份补丁：

```sh
git switch -c integrate/fingerprint-v26-v30 0445d5fba512a17186434e953950864bae1663e6
git am /path/to/handoff/patches/*.patch
```

本地缺基线时，先正常获取原仓库的 `release/gecko-2.0.25` 分支。若开发中的 2.0.25 已有更新，将这五份补丁作为可审查增量，按顺序解决冲突；不要覆盖新的配置、保护或存储修复。包内 `combined.patch` 可供审阅，不能与五份补丁重复应用。

## 可复现检查

需要 JDK 17、Python 3、Node.js。统一脚本可选择下载两个现有项目固定 SHA-256 的小型 Maven JSON 依赖：

```sh
python3 tools/fingerprint/run_first_five_handoff.py \
  --java /path/to/jdk-17/bin/java \
  --prepare-dependencies \
  --android-jar /path/to/Android/sdk/platforms/android-35/android.jar \
  --require-ui-compile
```

也可使用真实 Android 37.1 平台 JAR。没有 Android JAR 时可省略最后两项，报告将明确 UI 编译未执行。脚本不会下载完整 SDK、运行模拟器、访问检测站或更改模板。

输出在 `work/first-five-handoff/verification.json`。新纯模型使用桌面和 Android JSON 两套运行时；已有控制器和原生握手回归保留。UI 检查使用真实 Android framework 类，但应用／Gecko 边界为编译 doubles，**不是完整应用编译或运行验收**。
