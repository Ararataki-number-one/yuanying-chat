# 2.0.35（条件开发候选）

本地草稿策略在排队前捕获配置修订，关闭或切换保存策略后，旧排队任务不能重新存入可选草稿副本；独立的发送与归档记录继续保留。页面启动时使用固定数量的可信编辑与组合输入事件记录代次，正在组合输入或已有更新操作时，旧恢复任务不能覆盖新输入或清除活动组合状态。

草稿恢复保留 textarea 的选区方向，并对受支持的段落、换行、行内内容及原生 DIV 行结构记录有界 UTF-16 选区位置。包括直接 BR 端点的前向和反向范围；映射后的全文必须与已有草稿序列化完全一致。未知富文本形状、超限内容或无效元数据保留浏览器当前选区并说明未覆盖。

继续使用 GPT 原网页输入框、已有原生输入与内核补丁；不新增聚焦、提交、点击、刷新、轮询、DOM 观察器或数据库。原有文档、线路、阅读位置、手势、输入区、网页错误、忙碌状态和可信稳定期检查保留。

版本为 2.0.35 / 88，内置扩展为 2.0.35.88。本离线前缀继承拟定 2.0.34 树，尚未绑定正式 2.0.34 提交。发布前需对齐前序各版最终源码并通过完整构建、原生 SDK、caret 兼容和既有发布门禁。
