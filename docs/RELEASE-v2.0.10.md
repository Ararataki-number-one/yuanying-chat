# 2.0.10：选路修正、更新下载提速与可复制诊断

- 修复自动优选可能被当前入口的旧网站测速记录锁住的问题。只有当前入口和备选入口都有近期、可比较的网站记录时，才按网站表现比较；否则使用完整线路的有效探测。保留允许节点池、切换冷却、忙碌保护和固定出口，不因单次数字波动频繁换线。
- 大型更新文件支持双连接分段下载，两段分别保存断点。服务端不支持可靠分段时沿用单连接；文件身份、大小、哈希、原签名和线路失效检查保留。不会偷偷改用直连或更换固定出口。
- 在“网络 → 窗口网络 → 更多 → 窗口详情”加入“查看耗时诊断”，可查看并复制对应环境的数据。不触发额外测速、重连或网页刷新，不导出订阅链接、账号密码或聊天内容。
- 诊断区分检测网站的建链、TLS、首字节耗时和 ChatGPT 网站首响应；旧记录明确标注，不把未观测项目写成 0 ms。

受控主机 HTTP 测试中，双连接下载 8 MiB 文件从约 859 ms 降至 497 ms。这仅验证分段机制，不能代表手机公网收益；共享带宽、出口限速或服务端等待仍可能影响速度。不承诺将当前线路 400 ms 降至 200 ms。

沿用单 GeckoView 和 ChatGPT 原网页，不改变环境存储目录、登录数据或固定出口绑定。ARM 真机、真实账号和用户线路的提速幅度尚未验收。按用户明确指令发布，发布授权不等于真机验收通过。
