# 会话界面流畅性专项

在本地提交 `1e3086a8e38ce736a9ae7acaaf54aeb40ca71e49` 的基础上，继续减少会话页在回复生成、滚动、输入和下载时的重复工作。本轮没有新增操作入口，也没有改变网页输入、发送或恢复规则。

## 实际改动

会话通知、下载通知和一秒定时刷新共用原生帧更新。模型引用仍立即同步；定时刷新和下载事件只刷新展示，不重复绑定会话状态。因此用户关闭的相同错误提示不会被定时器重新弹出，真正的会话状态变化仍通过原有观察器更新。帧的启停由 Activity 生命周期管理，兼容延后创建和测试窗口对恢复方法的覆盖。

顶部工具栏和网络指标共用帧回调。每次执行时读取当前会话，生成一份网络数据，原样交给显示与保存；没有跨帧保留旧的网络判断。原有环境身份检查、保存范围、五秒稳定状态保存节流和异步加密写入继续执行，暂停和销毁会取消排队刷新。

网页观察器复用按钮候选集合，避免每次读取回复状态都遍历全部历史按钮。插入、移除、移动或相关属性变化会使集合失效；同一 JavaScript 任务内先同步处理待交付的 DOM 变更。文字、可见性、禁用状态、错误和完成状态继续实时检查，不缓存这些判断。没有标签的控件保留文字回退，旧版本观察辅助对象仍可使用实时查询。

加载提示仅在显示内容或显示状态变化时写入控件。网页已经显示时，不再更新隐藏的重试按钮；空白及内存延后状态不会反复设置相同文字、重新取消动画。二十秒慢连接提示、横竖屏布局、错误详情、无障碍文案，以及淡出过程中重新显示的保护均保留。

## 固定工作量对照

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 观察器预热后，600 个带标签历史控件、40 次流式更新中的整页按钮查询 | 200 | 0 |
| 同一网页场景的控件标签读取 | 120,880 | 160 |
| 一组集中网络刷新所需的完整网络数据生成 | 2 | 1 |
| 相同加载状态连续 100 次更新：已显示网页的隐藏按钮文字赋值 | 100 | 0 |
| 相同加载状态连续 100 次更新：空白页文字赋值 | 200 | 0 |
| 相同加载状态连续 100 次更新：内存延后页文字赋值 | 300 | 0 |

混合 1,000 次会话通知、1,000 次下载通知和一次定时刷新，只排入一次会话展示帧；下载及定时事件单独到来时不会重新显示会话状态消息。对照数据来自实际源码的受控工作量计数，不是手机 FPS、卡顿率或响应耗时。无标签的历史控件仍需实时读文字，不承诺同样的标签读取降幅。

## 验证边界

记录在 [会话流畅性验证](../verification/chat-smoothness-v2.0.47-candidate2/README.md)。覆盖同任务 DOM 变化、回复与错误、上传状态、输入保留、滚动观察、网络身份、暂停恢复、原生帧合并及加载动画竞争。38 个完整生产 Java 文件通过真实 Android SDK 37.1 API 联合编译，周边应用接口使用明确的编译边界；这不等于完整 Gecko 或 APK 构建。

动态加载的网页脚本不属于内置扩展的版本复用入口，故没有改动应用版本或扩展版本。尚未生成本轮 APK，未完成新代码的 Android/Gecko 设备帧率与真实账号验收。
