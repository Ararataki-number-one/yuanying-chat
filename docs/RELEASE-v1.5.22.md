# 1.5.22

- 修正网页异常放大、内容横向超出手机屏幕的问题。缩放改用 Firefox 原生合成器提供的实际像素比例，避免受网页 DPR 和强化隐私保护影响。
- “适应屏幕”恢复 100% 后复位横向视觉偏移，保留当前纵向阅读位置；不会重新加载网页。
- 页面首次显示和恢复缩放时等待 Firefox 的真实缩放数据与当前页面的布局宽度，避免用初始化默认比例误放大。切换页面但比例未变时仍能恢复保存的选择；缩放动作尚未完成时不叠加新的调整。
- 每个环境继续独立记住缩放选择；已有登录、草稿、固定出口、网络配置与官方网页保持原有逻辑。

版本为 1.5.22 / code 48，沿用原包名与原签名。验证结果与公网地址将在当前源码的实际 Android 回归完成后补齐。
