# 2.0 候选版手机验收

请在 Android ARM 手机上覆盖安装候选版，保留现有应用。记录手机型号、Android 版本、输入法、安装包版本与下载链接；逐项回复“通过 / 失败 / 未测”，失败时记录操作步骤。删除和重置只在临时环境中测试。

本版继续使用官方 GeckoView 与 ChatGPT 原网页。云端的合成内存压力和受控网页检查不能代替手机持续使用，也不能证明某台手机可以同时运行固定数量的环境。

| 项目 | 操作与通过条件 |
| --- | --- |
| 覆盖升级 | 从现有 1.7 或旧版直接安装；环境、登录、入口与固定出口、模板、草稿和已保存文件仍在。不要卸载后降级。 |
| 输入与阅读 | 使用百度输入法连续输入中文、选择候选词、混合英文、移动光标和删除；长回复、公式、代码块可滚动，横竖屏与缩放适合屏幕。记录光标跳位或持续卡顿的触发步骤。 |
| 登录弹窗返回 | 从原网页完成实际登录或授权并返回聊天页，随后输入、生成回复和添加附件；原页面继续工作，回复或上传不会被误当作空闲。 |
| 图片和文件 | 系统选择器正常打开，选取图片和文本文件后网页出现附件；连续两次选择、取消选择器、切换环境再返回，未完成上传不被提前释放。 |
| 回复和后台恢复 | 发起长回复后切到另一环境、再切到其他应用并返回；保留原任务，不重复发送，不异常退出登录。完成提醒仅在主动开启时出现。 |
| 多环境 | 两个临时环境分别保留不同草稿或登录；轮流前台使用并在后台生成回复或上传，状态不串用，当前聊天保持可操作。记录同时使用数量、卡顿与系统关闭情况。 |
| 内存等待 | 日常多应用使用时，如果出现“手机内存暂时紧张”，已打开的环境与任务仍在；关闭不需要的其他应用后重试，可以打开原候选地址。没有出现该状态记“未测”，不要据此认定低内存路径通过。 |
| 下载与续传 | 下载真实生成的文件并核对内容；更新包下载暂停后继续，大小正确。删除已下载安装包后，其他下载和环境数据仍在。 |
| 网络身份 | 切换入口后固定出口不变；更新入口、出口订阅各自保留有效选择。健康会话不因校验服务暂不可用被误断。 |
| 模板与自检 | 保存模板后核对期望、已应用与实际观测；忙碌时保留当前任务，空闲后应用。未覆盖能力和 Worker 请求头差异继续如实显示。 |
| 复制、重置和删除 | 复制临时环境的配置，副本不带登录与草稿；重置副本后配置与已保存下载保留。删除后同槽新建，旧任务、登录和回调不返回，原环境不受影响。 |
| 持续使用 | 正常使用至少一轮较长会话，记录是否反复登录、白屏、任务丢失、异常发热或耗电；与同一手机、同一网络上的 1.7 使用情况比较。 |

## 已知范围

原生输入光标偶发回退尚未确认修复，单次受控输入通过不代表百度输入法全部路径通过。遇到文字顺序异常时，保留操作步骤与版本记录。

独立时区及 Canvas、WebGL、音频、字体的自定义原生控制尚未启用。桌面页面的部分 Worker 联网请求仍使用官方 SDK 的移动默认 UA；页面与 Worker JavaScript 一致不代表 HTTP 请求头全部一致。

本版不会根据主机模型或单次 MemoryInfo/PSS 观测宣称手机容量、帧率、网络延迟或耗电已经改善。正式发布以实际手机检查结果为准，失败与未测项目保留记录。
