# PocketChat 2.1.14（116）

- 配置备份按原有格式导出。恢复配置时，如果选择文件的界面被系统重建，仍可继续。配置备份只包含允许的设置项。
- 创建、复制和修改环境时，会核对环境身份。副本保留首页和所选内核，并使用独立的网页与登录资料。保存失败时，表单会保留输入。
- 重置或删除环境前会检查旧下载记录。发现记录损坏时，环境保持可用，已有索引和保存文件会保留。临时写入失败可重试。
- 登录重置会清理旧 Gecko 页面地址和未完成的临时下载。旧下载索引可重试迁移，已有保存记录与删除标记会保留。Gecko 读取到不完整的网页记录时，会保留现有离线副本。
- Gecko 仍是默认内核。独立 Chromium 由环境设置在线下载，沿用系统直连、内置线路、固定代理和强制 VPN。安装条件与使用范围见 [双内核发布说明](RELEASE-v2.1.13.md)。
