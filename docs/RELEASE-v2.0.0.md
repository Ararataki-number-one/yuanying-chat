# 2.0.0 候选：输入修正与保留任务的资源保护

基于官方 Firefox 157.0.1 / GeckoView，继续使用 ChatGPT 原网页，继承 1.6 的独立入口/出口配置、1.7 的模板请求与分上下文观测。本候选仅对 GeckoView 的 `GeckoEditable` 输入处理类加入源码修正，使用独立的运行时 SDK 坐标；其他 SDK 类、原生库和资源的字节比对已确认不变。

- 手机确实内存紧张时，先保留已打开环境和进行中的任务，新的环境显示可重试的页面内提示。
- 内存等待保留地址，不误报网页超时、重连网络或重发消息。
- 回复、文件选择和准备、未完成附件、下载、设置与恢复期间保持已有会话；重复附件选择不会被旧回调提前释放。
- 空闲环境仅降低保留会话的活跃度，不自动销毁网页、退出进程或清理登录数据。
- 原网页资源观察只检查相关控件，普通长回复文本与无关列表变化不增加全页扫描。
- 输入修正限于特定的单字符提交与折叠光标路径，保留显式选区及原有输入回退处理。原 burst 输入测试不变，另加 14 项受控编辑检查。

当前候选的原 burst、14 项编辑检查和资源 174 项同一已安装 APK 门禁尚待实际 Android 执行与通过；旧失败报告继续保留，不作为本候选通过证据。构建与字节比对不能证明输入行为已修复。

独立时区、Canvas、WebGL、音频和字体的自定义原生控制仍不支持。没有真实 ARM 容量、实际帧率、登录保持或网络延迟改善的验收声明。云端 Android 资源诊断使用明确的合成压力控制；实际 MemoryInfo/PSS 数据只是当次观察。正式发布仍需安装候选包后的手机使用清单。

官方 SDK 仍有桌面 Worker fetch 请求头使用移动默认 UA 的范围限制，原始差异继续显示；本候选未修复这项一致性问题，也不宣称完整指纹能力。

光标修正的实际效果尚待验证；ARM 手机上的百度输入法、真实 ChatGPT 登录、编辑与持续使用仍请按 [手机验收清单](PHONE-ACCEPTANCE-v2.0.md)验证。保留原包名与原签名，向前覆盖安装；不要卸载现有应用或通过卸载降级。
