# 2.0.2：会话环境栏自动收起

启动时，顶部环境名称与网络状态两行默认收起，让出网页空间。向下滑动网页或再点底部“会话”可以展开，向上滑动网页或环境栏再次收起。切回应用保持原来的收起状态，不自动展开。

收起跟随单指阅读手势，只在手指离开后改变外层布局。环境栏上的向上滑动不会误触菜单。普通点击、横向阅读代码、双指缩放、长按选字、键盘输入和无障碍浏览不触发自动收起。没有定时收起，也不增加提醒。

保留单 GeckoView、ChatGPT 原网页与现有环境隔离。收起不重新加载网页、不重新创建浏览器会话，也不改官方网页的输入框和消息界面。继续包含 2.0.1 的附件选择、页面连续性及下载列表修复。

沿用原包名与签名，覆盖安装保留现有环境和数据。云端受控回归与真实手机使用分别记录；正式发布使用通过手机验收的同一 APK，具体见 [本版手机验收](PHONE-ACCEPTANCE-v2.0.2.md)。
