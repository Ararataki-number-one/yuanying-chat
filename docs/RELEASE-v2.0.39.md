# 2.0.39（条件开发候选）

当前网页进程在后台退出、原有自动恢复额度已耗尽，且返回前台时仍没有错误提示的情况下，补充原生提示：“网页多次退出，自动恢复已暂停；请检查连接后点按重新加载”。已有恢复额度、时间窗口、恢复分支与健康页面激活逻辑继续沿用。

新增分支仅更新页面提示、状态及导航失败字段，并调用已有界面通知。它不调用失败或导航结束处理，不创建、取消或替换独立的网络重试，不重置重试令牌和次数，也不发送或重发聊天。

受控主机检查覆盖后台退出、额度耗尽、已有提示、过期窗口、无可用线路及已排队的独立网络重试。它们不能代替真实 Android 生命周期、Gecko 进程退出、锁屏、长时间后台及手机验收。

版本为 2.0.39 / 92，内置扩展为 2.0.39.92。本离线前缀继承拟定 2.0.38 树，保留 2.0.37 附件处理及 2.0.32 权限拒绝处理；尚无正式 2.0.38 前序提交。发布前需对齐实际前序源码，完成真实 SDK 构建与原发布门禁。当前未提交、未签名、未发布。
