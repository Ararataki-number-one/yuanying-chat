# 原生外壳视觉调整

以 2.0.12 / 65 为基线，参考苹果平台应用的布局与交互，自行实现原生 Android 组件。

- 中性灰页面背景、实色阅读与列表区域、蓝色主要操作；浅色与深色分别校准文字对比度。
- 默认收起的环境胶囊使用小面积半透明材质和展开提示；展开、上滑收起与只读网络状态沿用原交互。
- 环境列表与应用设置使用圆角分组、细分隔线和统一主副文字层级；列表操作和多选继续可用。
- 网络卡片、下载卡片与输入框统一圆角、间距和表面颜色；下载进度更新继续复用已有行与滚动锚点。
- 会话、环境更多菜单与网络快捷菜单使用底部浮动面板；编辑表单和危险操作确认保留居中布局。
- 动效仅作用于原生控件；胶囊只淡入，不逐帧改变网页视口。关闭系统动效时不播放胶囊动画。
- 字体采用 Android 系统字体，图标和材质自行绘制，没有引入参考应用的品牌素材或代码。

单 GeckoView、原网页、登录目录、Cookie、草稿、网络配置和线路切换策略沿用现有实现。主题继续通过原有外观事件同步到网页。

验证入口：

- `tests/browser-runtime/AppearancePaletteTest.java`：主题往返、重复应用与 AA 文字对比度。
- `tests/gecko/run_ui_visuals.py`：生产界面在 360/412 dp、双倍字体及深色模式下截图；保留既有可信点按、原生输入、顶部栏收起与阅读断言。
- `tests/gecko/run_appearance.py`：实际系统主题事件、输入选区、弹窗和持久化。
- `.github/workflows/gecko-integration.yml`：正式包及独立回归包构建与 Android 设备回归。

界面截图、受控设备回归与用户 ARM 真机验收分别报告，不互相替代。
