# 原生外壳视觉调整

以 2.0.12 / 65 为基线，参考苹果平台应用的布局与交互，自行实现原生 Android 组件。

- 中性灰页面背景、实色阅读与列表区域、蓝色主要操作；浅色与深色分别校准文字对比度。
- 默认收起的环境胶囊使用小面积半透明材质和展开提示；展开、上滑收起与只读网络状态沿用原交互。
- 环境列表与应用设置使用圆角分组、细分隔线和统一主副文字层级；列表操作和多选继续可用。
- 网络卡片、下载卡片与输入框统一圆角、间距和表面颜色；下载进度更新继续复用已有行与滚动锚点。
- 会话、环境更多菜单与网络快捷菜单使用底部浮动面板；编辑表单和危险操作确认保留居中布局。
- 动效仅作用于原生控件；胶囊只淡入，不逐帧改变网页视口。关闭系统动效时不播放胶囊动画。
- 字体采用 Android 系统字体，图标和材质自行绘制，没有引入参考应用的品牌素材或代码。

单 GeckoView、原网页、登录目录、Cookie、草稿、网络配置和线路切换策略沿用现有实现。主题继续通过原有外观事件同步到网页。

验证入口：

- `tests/browser-runtime/AppearancePaletteTest.java`：主题往返、重复应用与 AA 文字对比度。
- `tests/gecko/run_ui_visuals.py`：生产界面在 360/412 dp、双倍字体及深色模式下截图；保留既有可信点按、原生输入、顶部栏收起与阅读断言。
- `tests/gecko/run_appearance.py`：实际系统主题事件、输入选区、弹窗和持久化。
- `.github/workflows/gecko-integration.yml`：正式包及独立回归包构建与 Android 设备回归。

界面截图、受控设备回归与用户 ARM 真机验收分别报告，不互相替代。

## 全界面细节改进

以 2.0.13 为后续改造基线，继续保留单 GeckoView 和官方网页。参考项目用于交互和布局研究，使用自行绘制的图标及 Android 系统字体。

| 范围 | 实现内容 |
| --- | --- |
| 顶部与导航 | 紧凑胶囊、只读网络条；环境名称打开快捷选择面板，管理入口进入完整环境列表 |
| 环境管理 | 独立标题与操作区、显示环境数量、搜索图标和清除按钮、大字体批量操作纵向排列 |
| 网络 | 入口／固定出口／目的地分层展示；完整节点名称可换行；刷新、详情、分享、危险操作使用统一图标与菜单 |
| 下载 | 文件名、环境、状态、时间、进度、错误、保存位置形成清楚层级；行与滚动锚点继续复用；文件菜单使用底部面板 |
| 表单 | 统一内边距、焦点边框、标签关联、可见字段键盘顺序、末项完成；单行与多行分别布局；密码显示切换保留内容与选区 |
| 选择控件 | 复选框、单选、开关与下拉框统一触控高度、文字和深色配色；下拉项允许换行 |
| 面板 | 矢量关闭图标、标题可换行、底部按钮按内容增高、大字体纵向排列；危险操作使用红色 |
| 状态 | 空列表有图标与下一步；加载只显示实际状态；关闭系统动效时立即切换 |
| 次级页面 | 启动介绍、反馈、模板、网页缩放、默认入口、订阅、出口及导入沿用相同设计组件 |

视觉验证矩阵扩展为 111 个当前源码界面案例，覆盖 360/412 dp、640×360 dp 横屏、双倍字体、深色模式及上述次级页面。测试矩阵定义不代表执行通过；实际结果以对应源码的 CI 回执为准。真实线路速度、ARM 手机及百度输入法验收分别记录。

界面矩阵在模拟器启动后优先执行，每完成 10 个案例保存一次 `in_progress` 检查点和合成截图。检查点用于复核与中断诊断，不满足发布验收；完整矩阵及后续原生交互仍须通过。输入、主题、分享、文件、连接与环境回归继续保留，未因调整顺序而跳过。

截图复核还发现并修正了原生颜色选择器的启用状态查询：采样按下、选中和默认颜色时显式携带 `state_enabled`，避免命中停用分支。原生 Android 回归检查启用／停用颜色和标题透明度在主题往返后仍正确。编辑页标题最多显示两行，原有浏览器界面案例使用长环境名称验证内容仍可操作。

模板表单使用统一 Modal：正文可滚动，保存与关闭固定在底部；原生截图断言两项操作在普通、双倍字体和横屏均完整可见。

双倍字体下，环境数量与操作分行，多选数量、全选和批量操作纵向排列。每个环境管理布局案例补充真实多选、全选与返回操作，并保存操作栏截图，断言四项操作完整可见且至少 48 dp 高。

长任务曾因运行机器关闭而中断，且出现过一次安装包回读传输失败。验证现拆为一次编译、五个独立 Android 模拟器任务（界面、输入、文件、连接、环境模板）及最终汇总。同批正式／集成 APK 和 SDK 通过带源码、运行批次与逐文件哈希的归档传递；源码、run/attempt、APK 字节或报告冲突均拒绝合并，不传递签名密钥。每个既定 APK 回读与输入工作负载仍只执行一次，不增加重试或编译包替代。最终同时要求全部任务成功和原有发布验收通过。独立任务使用相同 APK 字节，不表示同一真机或同一浏览器进程连续运行。

网络库回归按同一命名环境卡片内的入口、固定出口与 ChatGPT 目的地三段检查，不再查找旧的一行箭头文本；错误出口、角色互换、其他环境提供的节点、不可见值或可点击网络值均不能通过该断言。

较长的订阅／出口详情中，删除等正文操作可能位于滚动区域下方。网络界面验证先确认指定弹窗，再在其唯一原生 ScrollView 内执行有限次真实滑动，找到启用且可点击的按钮后仍执行原有单次点按与删除确认。没有跨窗口滑动、程序直接调用或跳过引用数量／数据结果断言。
