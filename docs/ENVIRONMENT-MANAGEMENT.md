# 环境管理与配置结构

本次调整参考 AdsPower 常见的环境列表与分组配置思路，结合 Android 手机和当前项目能力组织页面。当前网络未能访问 AdsPower 官方页面，未将产品最新截图作为已核实依据。本项目继续使用 Android System WebView，不新增桌面浏览器内核或指纹伪装承诺。

## 导航与作用域

| 入口 | 作用域 | 用途 |
| --- | --- | --- |
| 会话 | 当前环境；从独立管理页进入时返回最近使用环境 | 原网页 / 简洁聊天、历史、附件与发送记录 |
| 环境 | 全部环境 | 新建、搜索、分组、收藏、排序、编辑、默认启动环境 |
| 下载 | 全部环境 | 文件、进度和任务汇总；操作路由到所属环境 |
| 网络 | 页面标题下明确显示所属环境 | 连接配置、订阅入口、节点选择、出口核对、连接诊断 |
| 设置 | 全局应用 | 启动入口、界面说明、系统通知和电池权限、帮助与支持范围（从管理页打开不启动浏览器） |

底部“会话”保留当前环境，不切换到默认启动环境；默认环境只控制应用启动。列表与下载页没有聊天实例时，使用最近打开的环境，无记录时使用默认环境。

## 环境列表

环境使用稳定的两位编号。卡片突出名称、分组、网络状态和最近使用时间，标记收藏、默认启动与未应用的配置草稿。已停止或状态过期的环境不会显示为当前已连接。保护等级在环境编辑页查看。

“打开环境”是主要操作；编辑、分组与备注、收藏、默认启动和网络配置统一收进“更多”。长按卡片或点击“多选”进入批量管理，点击卡片或复选框选择环境。

支持名称、编号、分组与备注搜索；分组筛选与状态筛选可以叠加。排序可选编号、最近使用或名称。没有匹配结果时提供重置筛选。

分组与备注是本地管理资料，可在列表“更多”中修改，无需启动浏览器。分组最多 12 字，备注最多 120 字，名称最多 24 字。登录、Cookie、账号内容和凭据不进入共享目录表。

批量管理支持分组、收藏与取消收藏。全选仅作用于当前搜索和筛选结果；已选择的环境在筛选后保留，底部明确提示筛选外的选择数量。批量分组表单再次说明完整作用范围，可选已有分组或填写新分组，留空表示未分组。每次批量写入使用数据库事务，仅处理已创建环境；备注、编辑草稿和各环境网络配置保留。返回键先退出多选，不触发环境打开。

## 环境编辑

| 分组 | 内容 |
| --- | --- |
| 基本信息 | 名称、分组、备注、平台、隔离范围 |
| 网络配置 | 当前已生效的网络方式与状态，进入单独的连接配置流程 |
| 浏览器 | 三档保护、加载前保护状态、实际内核与 UA、屏幕、系统语言和时区、自检入口 |
| 使用偏好 | 会话恢复、后台和通知、下载与存储、临时文件清理 |

“存草稿”只保存填写内容，“保存环境”才应用配置。未保存的修改在退出时提示处理。前往网络页时自动保存编辑草稿；网络表单单独保存并连接，再返回编辑页可继续草稿。

名字或分组变化不重载网页；保护等级变化需要任务结束后应用，并重新建立连接。未改变保护等级时，旧 WebView 不会因为缺少新保护能力阻止修改名称。

## 网络与能力边界

手机网络 / VPN、应用专用代理和内置订阅 + 固定出口沿用实际连接能力。订阅和节点页仅在内置模式中显示可执行操作。网络切换、参数保存、订阅刷新与节点切换均检查未完成任务。

自定义 UA / 指纹、独立语言时区、多订阅、自动化、环境删除和登录数据清理没有实现；统一放在“设置 → 功能支持范围”，不占据常用表单。已有第三方扩展接口保留。

## 数据兼容与验证

共享目录数据库从 v3 升至 v4，为环境新增 `group_name` 和 `notes`，默认空字符串。已有名称、收藏、编辑草稿及环境状态保留；v1/v2 的连续升级路径保留。各环境的账号存储路径、通知编号、网络凭据加密与下载目录不迁移。

当前回归入口：`WindowHomeTestActivity` 检查旧目录迁移、卡片、分组和备注搜索、编号搜索、排序与路由；`DesignUiTestActivity` 检查导航、全局设置作用域、网络模式限制、环境保存及网页文档保留。测试包构建命令见 `docs/BUILD.md`。历史 `verification/` 结果不代表本次运行结果。
