# 2.0.25：本地双报告与独立深检参照

versionCode 78，扩展版本 2.0.25.78。开发候选，尚未发布；正式下载仍以最新 Release 为准。

- 自检首页保留保护状态、本机检查、深检与结果摘要。原始字段及网络检测、服务地址和第二来源放到默认收起的区域；展开界面不会自动检测、切换模板或刷新聊天。
- 每环境可主动保存一份标准报告和一份强化报告，分别查看模板、设置回读、API 操作与人工兼容记录。首次保存和替换后的人工项目均为“未测试”，不会生成保护分数或自动宣称真机通过。
- 主页面、Dedicated Worker、同源 iframe、受控跨源 iframe 分别固定有界参照。仅同执行环境、来源、配置和探针／内核／应用版本满足条件时比较；状态、图形输出或哈希变化不直接判为泄漏。旧主页面参照保留兼容，清除一个参照不清除其他参照或最近八条观测。
- 真实请求身份结果区分 Worker 脚本下载与 Worker 后续请求，保留桌面 UA 与 Worker 请求 UA 的已观察差异，不使用 JavaScript 属性覆盖伪造一致。

同手机对照流程：在同一环境固定手机版或电脑版、语言、检测来源与网络，先用标准模板完成深检并保存标准报告，再主动切换强化模板，等设置回读确认后以相同条件深检并保存强化报告。分别实际操作登录、百度输入法、附件、绘图、页面恢复、重启和后台返回，再在对应栏记录结果。模板或配置版本因切换而变化会如实列出；来源、版本、语言或显示方式等条件不同的输出不作同条件效果比较。

本地快照与人工记录保存在当前环境的加密存储，只在主动复制时导出。人工标记仅为用户记录，不是独立验收。未提供真实手机设备或记录时，受控测试不能替代同手机效果对照。

本轮没有统一电脑版与 Worker 的底层 HTTP UA，也没有新增 Shared Worker、Service Worker 或时区／GPU／硬件身份等自定义内核控制；它们仍需依据实际证据单独评估。ChatGPT 的登录、Cookie 和 Worker 不由这些本地参照操作清除。
