# 2.1.2 · Worker 请求策略与原生网页时区

版本号 `2.1.2`，版本代码 `104`。本页说明实现范围，正式安装包及验证结果以 GitHub Release 为准。

## 保留现有内核

Gecko 沿用原有 GeckoView SDK 与原生库；Chromium 继续使用 Android System WebView。默认网站仍为 ChatGPT，两个内核均可切换网址。

## Worker 策略

Gecko 为应用允许的公共 HTTP、HTTPS 请求增加身份对齐：请求头采用当前环境真实 Gecko 会话的 User-Agent，覆盖经过相同网络请求链路的 Worker 请求。页面读取的身份、原生会话设置与服务端收到的请求头分别确认。底层 SDK 对内部私有地址的行为不因此改变；这项策略不等于完整桌面身份、TLS 或 HTTP/2 指纹伪装。

Chromium 新增可选的 Worker 限制，默认保持允许。限制模式在文档开始阶段限制页面及受支持框架新建 Dedicated Worker、Shared Worker 和注册 Service Worker，并使用原生设置阻止 Service Worker 联网。设置需要当前环境身份、配置版本与原生回读一致后才放行；网络线路重新建立不会取消已选的限制。

页面创建限制与原生后台联网限制分别显示。已有 Worker 不会因此全部停止，已经缓存的 Service Worker 内容仍可能执行。这些限制不是 Worker 内部指纹伪装。

## Gecko 原生网页时区

新增每个环境独立保存的跟随出口 IP、系统、UTC 与 IANA 时区选择，通过应用自带扩展访问现有引擎的原生上下文时区设置，不替换页面 `Date` 或 `Intl`，不修改手机系统时区。

新环境默认跟随出口 IP；已保存的系统或手选时区继续保留。查询由 Gecko 自带扩展沿当前浏览器代理与 DNS 线路访问 `ipwho.is`，使用返回的 IANA 时区，再等待原生设置确认。查询失败会保留目标网址并结束加载提示，可重试或明确改为手选；不把系统时区标为 IP 匹配。受控测试使用本地合成地理服务，实际公网提供商连通性尚未核验。

线路或 DNS 改变后，旧 IP 匹配失效，现有页面、回复、草稿与任务保留；确认重开或重试才准备新会话。强化保护优先沿用内核 RFP，不查询或声称 IP 匹配。

自选时区在原生设置确认之前保持首次导航、恢复及重开操作等待。强化保护与自选时区冲突时保留原保护，并提示用户选择。自选时区暂时阻止不能保证首脚本前完成确认的新窗口；被阻止的有效公共网址提供“在当前页打开”入口，仍经过草稿与任务确认；系统时区模式保留原有新窗口行为。

原生设置回读与当前页面实际观测分开记录。修改配置、关闭或重建网页后，旧自检结果不再标为当前。现有内核的独立 Android 能力诊断中，页面、Dedicated、Blob 和 Shared Worker 的原生时区随设置改变；Service Worker 仍可读取系统时区，不能提供完整时区隔离。该差异会在设置和保存确认中提示。能力诊断不替代当前生产应用的保存、导航、恢复及各执行环境验收。

## 仍需分别验证的范围

Chromium 没有新增原生独立时区接口。硬件可控参数与 TLS、HTTP/2、HTTP/3 原生策略仍按后续独立阶段处理，本版本不声称已覆盖，也不承诺模拟任意设备或浏览器。

最终验证须包含原有完整回归、真实 Android Worker 请求与限制、生产时区配置链路，以及原签名公开安装包核验。主机测试、桌面浏览器结果与内核能力探针分别记录。
