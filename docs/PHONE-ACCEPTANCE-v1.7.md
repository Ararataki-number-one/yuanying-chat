# 1.7 候选版手机验收

此清单由使用者在 Android ARM 手机上执行。云端受控页面和 x86_64 模拟器的通过结果不能代替真实 ChatGPT 登录、百度输入法或长期使用验证。请记录手机型号、Android 版本、安装包版本及下载链接；逐项回复“通过 / 失败 / 未测”，失败时附触发步骤。

升级前保留现有安装和环境，不要卸载。候选版本号高于旧版，直接降级安装可能失败；卸载会清除应用私有登录和环境数据。涉及删除或重置的步骤只在临时测试环境操作。

| 项目 | 操作与通过条件 |
| --- | --- |
| 升级数据 | 从现有版本覆盖安装；环境名称、分组、入口与固定出口、草稿、保存的下载仍在。 |
| 登录会话 | 在原环境打开 ChatGPT；已有登录保留。真实登录后连续操作、切换环境并重启应用，检查是否异常要求重新登录。 |
| 中文输入 | 使用百度输入法连续输入中文、选择候选词、混合英文、移动光标及删除；文字和光标不被旧恢复任务覆盖，键盘不遮挡输入框。 |
| 附件 | 在原网页添加图片和文本文件；系统选择器出现，选择后网页显示附件，发送后正常使用。 |
| 下载 | 下载真实生成的文件；内容和大小正确。更新下载中断后继续；删除已下载安装包，确认其他文件保留。 |
| 长回复 | 阅读长回复、代码块和公式；横竖屏及缩放能适应屏幕，输入和滚动不出现持续卡顿。 |
| 后台恢复 | 生成回复时切到后台再返回；保留当前页面与草稿，不重复发送。后台完成提醒仅在主动开启后出现。 |
| 环境隔离 | 两个临时环境分别登录或保存不同网页状态；切换、重启后不串 Cookie、会话或草稿。 |
| 固定出口 | 调整入口后出口仍固定；正常连接不因测速网站暂不可用而中断，实际出口不符时仍阻断。 |
| 独立订阅 | 分别更新入口与出口订阅；失败保留旧有效快照，出口刷新不自动轮换正在使用的固定出口。 |
| 模板与观测 | 在临时环境选择标准或兼容模板、显示方式和语言。忙碌时先保存，结束后再应用；查看“期望配置 / 已应用配置 / 实际观测”，不把保存成功当作全部字段一致。切换两个不同语言环境并重启后重新自检。 |
| 生命周期 | 复制临时环境的配置，检查模板和网络设置被复制、登录和草稿没有复制。在副本中登录后重置登录数据，检查环境仍在、名称和配置保留，而目标登录/站点数据清空；最后删除副本并同槽新建，确认旧任务和数据未返回，原环境及已保存下载仍在。 |

## 自检结果的范围

页面、同源 iframe 和 Dedicated Worker 的公开 JavaScript 字段分别核对；网页可以影响采集结果。服务端请求头的受控验证不等于真实 ChatGPT 的所有联网行为。

当前电脑版的部分 Worker 联网请求仍使用官方 SDK 的手机版 UA。因此 Worker 的 JavaScript UA 一致，不能说明其 HTTP UA 一致。跨源 iframe、Shared Worker、Service Worker、自定义时区以及 Canvas/WebGL/音频/字体控制尚未提供完整验证或自定义能力，应显示“未覆盖”或实际支持范围。

强化保护属于实验配置；标准和兼容模板的验收不能代替强化模式的登录、附件、下载和音视频兼容性验收。未通过项目保留为失败或未测，不计入正式发布门槛。
