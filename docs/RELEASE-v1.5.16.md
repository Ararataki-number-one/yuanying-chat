# 1.5.16

- 修复恢复已有线路后没有补测延迟、手机网络和应用代理一直显示“延迟未测”的问题。自动检测只发送当前受保护线路的小请求，保留入口、固定出口和登录数据。
- 会话顶部普通字号缩至约 58 dp；大字体保留可读空间。网络状态仅展示信息，取消箭头和点击跳转，延迟独立显示。
- 普通通知只保留回复完成提醒，按环境与回复去重。等待回复、连接保活使用静默渠道，不显示进度和环境计数，不播放声音、不振动、不显示角标，并请求隐藏锁屏提示。
- 旧实测延迟标明“上次”；应用代理和手机网络的测量标为“连接响应”，不冒充内置入口与固定出口的完整线路延迟。

Android 要求运行中的前台服务保留系统提示，部分系统仍会在通知抽屉显示静默服务条目；后台回复检测和受保护连接继续保留。受控 Android 回归验证实际代理链、服务与完成检测；真实账号和真机长期使用仍需验证。
