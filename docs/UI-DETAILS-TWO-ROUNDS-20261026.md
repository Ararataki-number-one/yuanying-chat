## 基线与第一轮

基线为已发布 2.0.19 的源码 `739398a120706e3a9018d63d96630df7047890d8`，实际界面来自同源 Android 回归 `40224938151/1`。只读预研还查看了 App 字节相同的较早截图，并在本次基线中再次确认问题。

第一轮源码为 `2fde13cb715d61909ad093909969989c8bf63f4b`，原生截图运行 `40229064741/1` 完成固定 40 个场景：五个主页面的两种宽度和日夜外观、大字体、横屏及常用面板。实际看图确认，大字体设置标题不再留下单字“口”；同时发现说明仍可能拆开“应用”等词组，留到第二轮按语义收口。

第一轮 APK 的 SHA-256 为 `4e6512273a7224da91158bc338435dfd0acbc6a825f5013731323c6620f9beb5`。原诊断包包含完整测试 APK，超过当前工具的单文件传输上限；随后由独立只读导出运行 `40230946600/1` 提取原图片和报告。原 APK 只在导出端作流式哈希，原截图未重拍、未编辑。导出源码 `0655deeeae636869d308db2a73cf4f4fc9834b1e` 与截图源码分别记录。

## 第二轮实现

新的隔离评审者实际查看了第一轮全部 40 张图，没有读取实现和旧评审。第二轮集中处理以下可见问题：

| 观察 | 处理 |
| --- | --- |
| 横屏错误页次要按钮的可见高度仅约 30 dp | 空白页内容支持滚动，横屏恢复操作并排显示，保留原按钮最小高度和回调 |
| 大字体订阅地址占位提示裁掉 `Mihomo` | 输入内使用短 HTTPS 提示，完整 Clash / Mihomo 格式信息放到可换行说明 |
| 说明中的“应用”“默认启动”和短动作词组在词中断行 | 大字体语义分隔改为分行；只读说明中的短词组使用不换行控制，辅助朗读保留原始完整文字 |
| 长表单的滚动正文在固定按钮区上方截断，边界不明显 | 仅在正文确实溢出且存在固定操作时显示一条既有细分隔线，不新增布局高度 |
| 启动瞬间，一般的设置应用状态被显示为网页未打开的原因 | 在这一特定状态下优先展示现有网页／网络错误；未知时给出不虚构原因的恢复说明 |

不换行处理仅用于只读说明，不改变 EditText、输入值、实际地址或保存的数据。分隔线沿用已有日夜颜色，没有新增模糊、重阴影、持续动画或网页视口变化。
