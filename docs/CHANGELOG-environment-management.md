# 环境管理界面调整（未发布）

- 统一使用“环境”组织独立账号。管理界面改为浅色、白色卡片与蓝色操作重点。
- 环境列表新增分组与备注，支持组合筛选、编号搜索和三种排序。列表可直接编辑管理资料。
- 编辑页整理为基本信息、网络配置、浏览器、使用偏好。未保存修改提示存草稿，前往网络页自动保留编辑草稿。
- “会话”返回当前环境，默认环境仅用于启动。环境网络页面明确显示作用域，应用设置专注全局选项。
- 订阅和节点仅在内置网络模式展示操作。网络参数保存、订阅更新和节点切换补齐未完成任务检查。
- 未实现能力统一放入功能支持范围。保留三档保护与真实浏览器信息，沿用原有账号隔离和加密网络配置。
- 共享目录数据库 v4 新增分组、备注字段，保留旧目录的连续迁移路径。

当前版本号仍为 1.5.0，此记录不代表已发布版本。设备验证结果会单独记录，不沿用旧版 578 项检查摘要。
