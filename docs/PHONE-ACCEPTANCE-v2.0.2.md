# 2.0.2 正式发布前的手机验收

在 ARM64 手机直接覆盖安装 2.0.2 候选包，不卸载原应用。请记录手机型号、Android 版本，并按下面各项反馈“通过 / 失败 / 未测”。输入法沿用已知的百度输入法；源码与安装包 SHA 由发布记录填写，无需手工抄写。

云端受控 Android 回归和手机验收分别记录，模拟器通过不能代替真实登录、附件或持续使用。正式版使用此候选包的同一份签名 APK。

| 验收项 | 在手机上确认 |
| --- | --- |
| 升级保留 `upgrade-data` | 原有环境、登录、草稿、网络配置和已保存下载仍在。 |
| 登录 `login-session` | 完成登录、返回页面后继续使用，不异常重复登录。 |
| 中文输入 `chinese-input` | 百度输入法选词、移动光标、粘贴与删除正确；键盘显示时环境栏不意外收起。 |
| 附件 `attachments` | 点击添加图片与文本文件能打开选择器，网页收到附件；取消不产生附件。 |
| 下载 `downloads` | 文件可下载、暂停续传和打开；列表不跳动，下载中置顶，时间与排序正确。 |
| 长回复 `long-reply` | 启动默认收起；下滑网页或点“会话”可展开，上滑网页或环境栏收起；长回复、公式和代码可读，横滑与双指缩放不误触。 |
| 后台恢复 `background-resume` | 切到其他应用再回来，网页、草稿与收起状态仍在，不重复发送。 |
| 环境隔离 `environment-isolation` | 两个临时环境分别保留自己的登录、草稿和任务。 |
| 固定出口 `fixed-exit` | 更换入口后，固定出口保持所选身份；不符时仍执行保护。 |
| 双订阅 `independent-subscriptions` | 入口与出口各自更新，保留有效选择。 |
| 模板观测 `template-observations` | 自检可运行，期望、已应用及观测差异如实展示，未支持项目未宣称生效。 |
| 重置与槽位复用 `reset-and-slot-reuse` | 仅用临时环境测试；删除后同槽新建，不带回旧登录、草稿或任务。 |
| 资源策略 `resource-policy` | 当前聊天可操作，环境切换不误中断回复或上传；资源不足的未触发分支记未测。 |
| 持续使用 `sustained-use` | 完成一轮较长会话，无反复刷新、明显输入卡顿、任务丢失或异常发热。 |

未通过或未测的项目保持原记录，不据此宣称真机验收完成。自定义时区、Canvas 等深层原生能力，以及部分桌面 Worker 请求头一致性仍沿用 2.0 的已知支持范围。
