# 网络快照的环境身份隔离

这是 N15 的第二个独立修正。旧构造器只在判断新鲜度时局部比较环境
ID 和代次，而且允许没有 ID 的旧快照直接参与判断。IP、延迟、运行配置
和详情随后仍能读取同一个未过滤对象，导致其他环境的数据显示为“上次”。

现在先核对目录行和快照：ID 必须都是相等的非空字符串，代次必须是
实际的 Integer 或 Long，非负且不超过既有环境模型的 Integer.MAX_VALUE。
字符串数字、小数、布尔值、缺项和溢出均不能作为环境身份。不增加 UUID
格式限制，也不修改旧设置或目录身份。

顶层身份不符时，构造器与后续详情只得到空的运行投影。运行模式、是否
配置、健康状态、运行配置、IP、地区、入口、延迟和倒计时均不能来自
被拒绝的快照；已保存的设置和偏好继续提供原有配置展示。即使嵌套的
运行配置恰好含有当前身份，也不能挽救属于其他环境的顶层快照。
顶层身份正确、嵌套身份错误时，只从展示副本移除该运行配置。
原输入对象和加密快照均不修改。

同一 ID 和代次的真实旧读数继续按原规则显示为“上次”。缺失时间、
45 秒快照边界、60 秒未来时钟容差、120 秒采样和倒计时规则保持。
没有会话时生产 `live(null, n)` 仍产生无身份观察，不能凭当前槽位给它
补造身份。旧无身份快照在已配置环境中显示“状态待核实”，等待新的
有身份观察；无需清理登录、配置、Cookie 或历史。

验证执行完整生产构造器与实际详情消费者，双 JSON 的新 93 项检查
包含前后对照。原有 88 项顶部栏与 44 项捕获回归保留；其中旧“无身份
视为正常”的一条断言改为明确拒绝，其余功能断言保留。原设备 14 项
新鲜度用例和网络检查保留，另有 14 项明确标为受控身份投影的用例。
现有独立网络/界面测试里的手造正例附带匹配的受控模型身份，不能据此
声称生产会话、IPC 或真实线路归属已经验证。

本次只修改读取模型，不修改真实采样、探测、重连、固定出口、网页、
单 GeckoView 或消息流程。网页状态分层与快照 PID 关联仍是后续范围。
宿主结果和 API 编译不代表 Android、真实 ChatGPT、ARM 手机、百度
输入法或用户线路已经通过验收，也不构成性能提速证据。
