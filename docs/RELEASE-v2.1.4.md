# 2.1.4 · 原生指纹配置与浏览会话保护

版本 `2.1.4`，版本代码 `106`。本页说明功能与支持范围；正式安装包、原签名及绑定源码的验收报告以 GitHub Release 为准。发布要求保留原有检查，并完成全部 13 项作业与同环境 CPU、IP 时区、TLS 组合验收。

## 两种内核与网址切换

默认网站仍为 ChatGPT。Gecko 与 Chromium 界面都支持更换网址；Chromium 使用设备提供的 Android System WebView。每个环境分别保存两种内核的配置、登录与站点数据。

两核均有各自的指纹配置入口。Gecko 的强化保护使用原生 RFP 策略；Chromium 可配置原生 UA／UA-CH，以及页面中的 Canvas 图像读出、WebGL 调试显卡标识、音频复制读出和 WebRTC 创建限制。是否支持、是否回读、当前页面是否观察到效果分别显示，不把页面脚本保护称为系统或完整浏览器指纹仿真。普通站点不执行 ChatGPT 专用自动化脚本。

## 默认按出口 IP 设置 Gecko 时区

新环境默认查询当前已确认出口的 IP 与 IANA 时区，查询服务为 `ipwho.is`。已有手选系统或 IANA 时区继续保留。查询和原生设置确认完成后才打开目标网页；不替换网页的 `Date` 或 `Intl`，不修改手机系统时区。

查询失败会保留目标网址、结束加载提示，并提供重试或明确手选时区的入口。线路或 DNS 改变后，旧确认失效；当前页面、回复、任务和草稿保留，确认重开后再准备新会话。结果代表一次出口观测，界面区分查询来源、原生确认和网页实际观察。

线路改变后直接输入新网址，如果时区尚未重新匹配，也会结束这次加载提示并保留目标网址，提示重新匹配；当前页面与草稿继续保留，不会自动反复重试。

强化保护优先保留内核 RFP 策略，不将它标为 IP 匹配。无法在首次脚本前完成独立时区确认的新窗口会被阻止；有效网址提供“在当前页打开”入口，继续经过草稿与任务保护。

低内存暂缓网页启动后，恢复操作会保留目标网页并重新计算加载等待时间，避免被上一次超时打断。

环境设置新增自动延迟检测开关，默认开启。关闭后停止该环境自动发起的线路延迟探测，手动检测仍可使用；网络状态栏显示当前选择。

## Worker 与可控硬件参数

Gecko 的公共 HTTP、HTTPS 请求头采用当前环境实际会话的 User-Agent，包括经过相同请求链路的 Worker 请求。请求头与页面、Worker 内部属性分别确认。

Gecko 新增按环境保存的网页可见 CPU 数上限，作用于该环境整个 Gecko 运行时，不改变设备实际 CPU。自动模式沿用内核策略；自选上限通过真正冷启动应用。强化保护保持优先，可能使用内核标准值，不承诺网页始终返回所选上限。保存设置不会热改正在使用的环境。

Chromium 的 Worker 策略默认允许。可选限制模式在文档开始阶段限制页面及受支持框架新建 Dedicated／Shared Worker 和注册 Service Worker，并通过系统 WebView 的原生接口阻止 Service Worker 后续联网。页面创建守卫与原生联网开关分别确认；已有 Worker、缓存内容仍可能执行，已开始的请求不保证取消，也不因此伪装 Worker 内部指纹。

## Gecko TLS 协议控制

每个环境可选择内核默认协议或仅 TLS 1.3；内核默认不承诺固定协议范围。设置在真正冷启动时准备原生配置，并核验当前环境的原生 TLS 偏好回读；保存后显示待生效状态，当前回复、上传、下载和草稿继续保留。关闭网页或重新打开界面不等于冷启动。

此项控制作用于 Gecko 网页连接，保留原有 RFP、HTTP/2 与 HTTP/3 设置。应用独立下载器、连接检查及代理入口使用的其他 TLS 栈不在此覆盖范围。协议回读与真实网络握手分别记录。

## 已知范围

- 独立时区的原生设置范围是顶层浏览上下文，不能据主页面回读推断所有子框架或 Worker 均采用相同时区；Service Worker 仍可能读取系统时区。既有 Service Worker 在暖态切换强化保护后，CPU 观察值也可能保留旧值。
- Android System WebView 没有提供本应用可用的独立原生时区、CPU 上限或 TLS 协议控制接口；界面如实标明支持项。
- Chromium 的页面保护不覆盖 Worker 指纹、OffscreenCanvas、AudioWorklet、字体或完整硬件身份；WebGL 像素读出和音频实时缓冲保持原样。电脑版显示也不会把 Android 内核变成桌面操作系统。
- 本版本不提供任意设备、完整硬件身份、JA3／JA4、QUIC 或完整浏览器指纹仿真承诺。
- IP 时区验收使用固定域名映射的本地合成服务，不连接真实地理服务；本环境未核验该公网服务的可用性或 IP 数据准确性。

最终发布须绑定同一源码、SDK 与安装包，保留全部原验收，并完成 IP、CPU、TLS 及同环境组合检查。已有独立能力诊断或局部门槛通过，不替代最终组合源码的完整验收。受控模拟器结果不替代真实手机流畅度、输入法或 ChatGPT 官网兼容性验收。正式 APK 将继续使用原应用签名，最终发布结果以 GitHub Release 为准。
