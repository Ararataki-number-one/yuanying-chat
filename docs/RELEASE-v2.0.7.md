# 2.0.7：网页建连提速与问题反馈

- 固定出口可按需准备最多四条认证连接，减少网页同时建立多个新连接时的重复握手等待。保留连接复用、环境隔离和固定出口；测速值保持原口径。
- 设置新增“问题与建议”：填写问题或建议、预览后用 GitHub 账号提交，可添加截图和查看处理进度。草稿留在本机，不自动收集聊天、Cookie、日志或代理凭据。
- 反馈集中到项目 Issues，自动区分问题／建议并进入待筛选；维护者按复现情况、影响和维护成本筛选，再标记计划、处理、验证和发布状态。

本地受控测试中，四个并发新连接全部就绪的等待由约 245 ms 降到约 61 ms（每个模拟握手阶段设置 60 ms 延迟）。这证明特定建连场景的改善，不代表用户公网已经从 400 ms 降到 200 ms。已复用连接的线路往返时间仍由实际网络路径决定。

构建与 Android 回归结果见同版验证记录。真机、真实 ChatGPT 账号与用户公网线路仍需单独验证，不能以受控实验代替。
