# 2.0.33（开发候选）

原生 HTTP 下载开始时固定当前环境 UUID 与代次、网络设置、连接代次和已核实线路。内部代理在新连接前重新核对既有线路回执；需要外部 VPN 时使用已捕获并核实的 Android Network 打开连接。线路、环境、设置或默认网络归属改变后，当前尝试停止，不接纳替代线路、不回退直连，也不自动重发。保留部分下载数据，待用户恢复连接后手动继续。

每次流式读取使用快速归属检查，不新增逐块数据库查询或服务 IPC。下载尝试期间另有每 1000 毫秒调度的观察任务；这是调度间隔，不是 Android 上故障到断开的时限保证。内部线路尚未通知的静默故障仍依赖既有传输状态及 I/O 超时。现有通用失败状态与“已暂停”提示的文字一致性仍待后续处理，部分数据和手动继续保持。

本候选以 2.0.32 源码 `b196ff58a5b929e1446f62d5a459afb17355143a` 为起点，版本为 2.0.33 / 86，内置浏览器扩展同步为 2.0.33.86。继承已有站点权限、登录隔离、固定出口和发布门禁。

范围限于原生 HTTP 下载路径及既有内部线路准入检查。主机验证使用受控 Android、目录、服务及 HTTP 连接适配器；这不能证明真实 Android、Gecko、VPN、真实切网、公网包路径或手机泄漏防护，也不能证明 GPT 登录、聊天、后台请求、上传和下载的完整实际请求链已验收。不把单次出口查询视为完整覆盖，不宣称真实性能提升。

发布前仍需确认 2.0.32 已发布且本候选继承其最终源码，再执行本版源码绑定的完整构建与受控验收；当前未签名、未发布，也未完成真实手机验收。
