# 2.0.24：保护确认与按需指纹观测

versionCode 77，扩展版本 2.0.24.77。开发候选，尚未正式发布。

- 强化模式区分确认中、已确认与失败。原生设置回读未匹配前阻止新的网页、Worker 与恢复请求；有限重试，拒绝旧回执和旧准备任务。用户可主动保存标准模板，未打开浏览器的失败启动可安全恢复；不自动降级或重发消息。
- 本机自检新增按需 Canvas、离线音频、有限字体测量与 WebGL 能力检查，分别显示可用、受限、失败或未覆盖。普通自检不执行这些深测；采样有固定操作量与软期限，取消或离页后退役资源。
- 每环境加密保留最近八次真实页面观测，以稳定环境 ID／代次、配置、应用／内核版本和来源区分。屏幕旋转归一化，键盘与视口尺寸不用于诊断指纹异常；图形输出变化仅作为观测，不直接判断泄漏。
- 请求身份对照使用同一 GeckoView 的主动顶层导航，仅在完整确认空草稿、无附件和进行中任务后打开。检测页、Dedicated Worker 的 JavaScript 与服务端实际 HTTP 头分别保存，结果读取来自独立扩展后台控制请求；不将该控制请求的头冒充文档或 Worker。

没有内置在线检测站。需在自检中配置用户信任的 HTTPS 服务并逐次同意，地址为空时不发送请求。[参考服务与部署说明](../tools/fingerprint/README.md)包括固定协议、资源上限和来源边界。检测完成不自动跳回；仅由用户主动返回原聊天，不承诺保留原 DOM。

检测请求的 Cookie、认证与来源标记按精确作用域过滤，禁止重定向。旧 nonce、取消、过期、配置变化和冷恢复诊断地址默认关闭；不增加直连兜底，不清除登录或网页存储。检测失败不会自动重发聊天。

设置回读成功不代表全部指纹 API 保护通过，输出变化也不代表泄漏。当前 Firefox SDK 的电脑版页面与 Worker HTTP UA 不保证一致，对照会保留实际差异。独立时区、硬件及图形参数的原生自定义仍未开放。

验证范围由当前源码的原始测试记录确定。主机模型或 Chromium 检查不能代替 Android／Gecko；受控 Android 检测也不代表 ChatGPT 官网、真实手机、完整 DNS、IPv6、Shared Worker 或 Service Worker 验收。正式发布仍需完整同源码发布检查、原签名与公开 APK／更新入口验证。
