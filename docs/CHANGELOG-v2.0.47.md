# 2.0.47 候选2：订阅整条线路分享与聊天下载进度

本次修正候选1的后续反馈，versionCode 为 101，浏览器扩展版本为 `2.0.47.101`。

远程入口的整条线路直接分享完整 HTTPS 订阅地址与固定出口，不再选择入口节点。不含订阅地址的本地导入节点保留原有节点格式兼容。新增 schemaVersion 3，以 `entrySubscription.url` 表示入口订阅，禁止同时夹带单个入口节点。复制与文件分享复用相同编码，并在操作前检查所选配置版本。

导入预览不会请求订阅；确认后沿用现有订阅读取和原生解析流程。入口订阅及固定出口在同一次事务中保存，入口保留原地址及全部节点，可继续刷新。应用到环境时默认允许全部入口，出口仍由接收方重新核验。

聊天下载卡片读取现有任务的真实字节及状态，以已有下载通知和前台刷新更新。已知大小显示比例，未知大小显示动态进度；保存完成才显示已保存。卡片支持暂停、取消、查看结果及进入下载中心，离开聊天或环境身份变化时隐藏，不修改网页和浏览器连接。

验证覆盖实际分享对话框、剪贴板与文件字节一致性、加密库中的完整订阅导入和刷新，以及实际下载流驱动的 Android 卡片进度和暂停。缓存解析不会被描述为真实外网订阅请求。发布状态以本次 CI 和 Release 为准，不声称实体手机验收。

补齐线路报告中 SDK 后台请求 URL 的服务密钥脱敏。原始报告保留在执行用例的 CI 工作目录，公开报告标注为诊断 URL 副本并记录原始哈希；路由字段、受控请求、验收断言、隐私拒绝检查及实际应用网络逻辑不变。

## 更新通道

更新页提供正式版、测试版、候选版三个选择，保存偏好，自动检查和下载跟随所选通道。2.0.x 归入测试版，候选版按标签中的候选序号独立排序；正式版支持 2.x 及补丁版本，兼容历史 1.x。

`AppUpdateCatalog` 读取固定仓库的公开发布列表，筛选通道后核验对应清单。候选清单和下载器共同绑定准确的 `candidateN` 路径；包名、原证书、大小、哈希、架构和版本校验继续执行。现有 2.0.46 候选2的公开清单已用于兼容检查。

切换通道会清理旧通道说明、下载身份、进度和更新安装包缓存；运行中或暂停保留的下载不能被切换操作意外取消。旧校验回调失效，不会把旧进度当作新版本的续传进度。请求继续经过原有环境网络授权，失去授权不会回落为直接连接。发布工具增加 beta 通道，测试版和候选版均不推进旧正式更新源。

## 入口分享

入口订阅默认只复制或分享原始 HTTPS 地址，保留地址中的编码与查询参数，不打包单节点配置或节点列表。网络库订阅详情和入口节点菜单均提供该入口；节点菜单将单节点功能单独标作“仅分享此节点”。出口及整条线路保留原有显式节点配置分享流程与按钮文案。

地址分享复用现有配置快照桥接，保留已保存／正在运行来源、环境身份、版本和运行内核证明的检查。地址请求只读取入口选择记录，不读取节点载荷或出口，也不运行节点解析；复制或分享前重新校验。没有订阅地址的本地节点明确提示使用单节点分享。

Gradle 清单生成及扩展版本检查通过，版本读取代码通过 Android SDK 37.1 API 编译。用户上传的 JKS 已在本地核对，证书与原应用一致；未将密钥加入源码或发布材料。
