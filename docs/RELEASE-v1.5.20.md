# 1.5.20

- 同一环境、同一条已核验线路恢复连接时，保留浏览器连接池，减少重复建立代理链和 TLS 连接的等待。
- 取消后台测速时，同时结束内核中的探测请求，避免取消后继续占用连接直到超时。
- 延迟区分正常测量、包含建链的“首次”和“复测”。复测失败时保留首次有效响应的耗时，不把失败等待累计进去；自动选择低延迟节点时，只比较成功复用连接的结果。

版本为 1.5.20 / code 46，沿用原签名和包名。保留环境登录数据、隔离、固定出口保护，以及上传、下载和应用更新续传；不会自动重发聊天或改为直连。

这些改动减少应用自身造成的重复握手和探测干扰。受控测试尚不能证明你的实际线路已从 400 ms 降至 100 ms，也不能代替真机流畅度检查。
