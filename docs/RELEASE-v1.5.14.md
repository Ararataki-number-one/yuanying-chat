# 元婴期院士 1.5.14

- 新增可选的“低延迟优先”入口模式，在勾选池中按完整线路和网站响应优选，固定出口保持不变。
- 测速增加 ChatGPT 网站首响应与复测结果，网站验证限制单独说明。
- 空闲时小批量探测，回复、导航、上传与下载期间暂停后台检测，减少使用中的干扰。
- DNS 服务通过固定出口比较，结果按环境保存；更快的配置留到下次连接时应用，不为测速重载当前网页。
- 开启内核 DNS 缓存与 TCP 并行连接，复用成功的检测与出口核验连接。

入口选择路径：网络 → 编辑网络 → 入口选择 → 低延迟优先 → 勾选入口 → 确定 → 保存并应用。原有随机和手动模式继续保留。

使用原应用签名，可以覆盖安装。实际速度取决于订阅入口、固定出口和网站服务；优化不代表模型生成时间缩短。
