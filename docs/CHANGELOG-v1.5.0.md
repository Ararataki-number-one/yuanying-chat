# 元婴期院士 1.5.0 星空设计版

按本轮提供的完整产品设计图应用原生界面。此发布版将已验证的本地 1.5.0 构建同步到 GitHub，安装包沿用原签名。

## 界面与入口

- 新增品牌启动页、星空背景、原生品牌图标和蓝紫渐变按钮。首次展示品牌页，点击“立即进入”后进入默认窗口；后续启动默认直达指定窗口的原网页。
- 全局设置可以切换默认窗口，以及选择启动先显示窗口列表或直达原网页。
- 底部改为“默认、窗口、下载、网络、设置”五个入口，不恢复已删除的独立记录页。
- 原网页保留网站自身内容。应用外层增加窗口标题、默认标记、真实网络状态、模式切换与实际站点主机名。
- 窗口管理采用卡片、不同颜色的窗口图标、收藏、默认标记、上次打开时间及打开/编辑/更多操作。
- 窗口筛选支持全部、收藏、已打开、等待回复和异常。运行状态依据进程与实际状态记录，不等于账号登录或绑定证明。
- 创建窗口改为“基本信息、配置来源、完成”三步。网络配置可以从默认或其他窗口复制；自定义来源进入网络设置。登录、Cookie、聊天与草稿不复制。
- 窗口编辑分为基础、浏览器、偏好三个标签，保留编辑草稿和正式保存。实际系统、内核、UA、分辨率、语言和时区显示真实值。
- 设置分为当前窗口设置与全局应用设置。全局控制默认入口和星空背景，网络与保护等级仍按窗口保存。
- 网络中心分为方案、订阅、节点、出口、诊断，沿用已有连接、测速、入口切换、订阅更新、出口核实和诊断功能。
- 下载中心汇总所有窗口已保存文件和任务状态。任务操作回到对应窗口处理；进度索引不保存聊天内容、Cookie、临时下载链接或网络凭据。
- 隐私页保留三档保护、环境自检、变更提醒与明确的检查范围。
- 原有底部操作菜单、加载状态和文件预览配色一并适配。

## 未实现功能的处理

预留 `FutureFeatures.Adapter` 接入接口。未接入的项目显示“开发中”，点击说明入口不会改变现有网络或保护策略：自定义指纹参数、代理扩展、自动化脚本、其他平台、多个网络方案、多个订阅、完整分项诊断、完整泄漏检测、清理登录数据、删除窗口、清理下载记录、自定义下载目录和独立语言/时区参数。

图中的示例国家、城市、节点名称、型号、测量数值与账号绑定状态不会作为实际数据填入。分辨率和 UA 当前只读，不把 UI 开关做成未实现的伪装控制。

## 安装与数据

安装包沿用原签名，直接覆盖安装。不要先卸载。保留原有 Activity、进程、WebView 目录、偏好、数据库与加密密钥名称；共享目录表以升级方式新增 UI 设置与状态字段。

继续保留简洁/原网页聊天、模型与强度、会话历史、草稿、附件、预览、下载续传、自动保存、后台等待与通知、网络保护、8 个独立窗口和环境自检。安卓 8 可以用默认窗口；多窗口需要安卓 9+。

## 验证

使用独立测试包和拦截网页样本，不登录真实账号，不发送真实聊天，不访问公开 IP 检测服务。具体逐项结果与计数见源码包内 `verification/validation-summary.json`。截图中的窗口名、消息和下载文件来自测试数据。

保护与自检覆盖范围保持原有约束，不保证 VPN 不被识别或账号不被封。
