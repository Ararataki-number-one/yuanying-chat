# 2.0.40（条件开发候选）

普通文档绑定的环境检查在页面导航或线路归属失效时及时退役，取消已保存的原生 Future，并将现有 HTTP 连接交给既有工作线程断开。检查代次失效后，旧回调不能更新新页面结果。独立身份检查和服务检查继续按各自生命周期处理。

导航先标记为活动，再执行检查清理，避免清理期间被视为闲置。回复、待确认发送、状态不确定的附件、上传和下载等既有资源保护条件保持。原有 14.5 秒延迟看门狗仍在队列中，其运行与代次判断使过期任务不再适用；本次没有移除该回调。

版本为 2.0.40 / 93，内置扩展为 2.0.40.93。本离线前缀继承拟定 2.0.39 树，尚未绑定正式 2.0.39 提交。发布前需对齐前序正式源码，并完成本版源码绑定的完整构建、受控验收和既有发布门禁。

受控主机检查只验证任务取消、归属和保留活动的判断，不能代表 Android 生命周期、真实 HTTP 断开时限、手机内存、电池或速度改善。不承诺固定多环境容量。当前未提交、未签名、未发布。
