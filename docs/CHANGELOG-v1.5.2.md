# 1.5.2 · 更容易理解和放心操作的交互

这一轮先收紧页面层级：让人先看到当前状态和主要操作，减少重复说明和卡片堆叠；技术参数与低频设置点开后查看。同时整理返回、等待和刷新行为。版本号为 1.5.2 / versionCode 28，继续使用原版签名。

- 会话顶部合并为一行：环境名称与网站域名、显示方式、新对话和更多。正常连接时隐藏网络状态条，重新加载放在更多菜单。
- 环境列表把分组与排序收进“筛选”，搜索入口不再重复标签。卡片合并默认、草稿标记，备注在详情查看，最近使用与打开操作放在同一行。
- 网络所属环境压成一行；使用手机网络或应用代理时隐藏订阅、线路分页。连接状态优先显示，网络方式直接选择；诊断信息合并展示，日志与统计放在详情入口。
- 只读资料改为紧凑的标签和值，去掉类似输入框的边框。环境编辑移除重复的平台和隔离说明，UA、系统、时区等信息收进“浏览器信息”。下载位置说明点开查看，设置页去掉长篇常驻说明。
- 新建环境使用固定底部按钮。页面返回和系统返回先回到上一步，保留名称、分组和网络来源；修改后退出需明确选择继续填写或放弃创建。创建过程中显示实际等待状态，并禁止重复创建。
- 管理按钮、分页和返回入口使用至少 48dp 的点击区域；补上按下和禁用反馈，统一弹窗按钮样式。备注支持多行，编辑和创建表单在键盘打开时调整布局。
- 网络表单集中填写和保存，订阅更新、节点操作留在对应网络页面。取消或返回时可继续保留填写内容，错误标在对应字段旁，保存失败时保留输入。
- 长任务弹窗可收起，并明确说明任务继续。会话状态条和网络页可重新查看；任务未结束时阻止重复网络操作。节点测速在原弹窗内更新结果，关闭后不自动重新弹出。
- 网络、下载等会话内管理页的错误可在底部查看并手动关闭，完成提示短暂显示。独立设置和分组保存有结果提示。
- 下载列表更新保留滚动位置，切换筛选回到列表开头，恢复 Activity 时保留筛选；不同空列表说明各自状态并提供返回全部下载的入口。环境搜索无匹配时提供重置筛选。
- 独立下载和设置页面切换时结束旧的次级页面，减少来回堆叠；页面返回按钮与系统返回都回到调用页面。

本轮不改变数据库结构、账号存储格式、网络链路或消息重发规则。网络后续方向见 [交互规则与网络优化方向](INTERACTION-AND-NETWORK.md)。构建、原生回归和仍待真机检查的范围见 [本轮验证](../verification/interaction-round3/README.md)。
