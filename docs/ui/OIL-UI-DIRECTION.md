# Oil UI 校准方向

依据 [Oil UI 开源 skill](https://github.com/oil-oil/oil-ui/blob/81e194cefa51be3f3f41083aa3a8e28b1331cd23/SKILL.md)，版本 0.15.3。采用“已有方向深化”和“存量 UI 优化”流程，继续参考 [现有 HTML](yuanying_ui_reference.html) 与用户确定的 AdsPower 管理方式。

## 用户与主任务

这是 Android 上的多环境网页工具。会话页首先用于阅读和操作真实网页；环境页用于找到、打开和管理环境；网络页用于看清每个窗口的线路与状态。辅助说明服务当前判断，不作为首屏的主角。

## 视觉规则

- 沿用品牌、系统中文字体、现有线条图标和底部五项导航。蓝色表达主要动作和选中，绿色/橙色/红色同时配真实状态文字。
- 原生页面统一白色卡片、浅灰蓝背景和一个主蓝色。辅助文字使用更深的灰色；不靠低对比的小字制造密度。
- 环境名称为 16–17 sp；操作和正文为 13–15 sp；辅助信息为 12–13 sp。保留实际对象名、地区来源、未核验和失败状态。
- 卡片圆角 14 dp，按钮与输入框 12 dp，居中弹窗 18 dp。普通按钮不叠边框或阴影，列表卡片的打开操作用浅蓝强调；页面的新建或弹窗保存使用实心蓝色。
- 列表、表单与弹窗的通用按钮触摸高度维持 48 dp。会话头部保留既有紧凑布局（第一行 44 dp，整行网络入口 28 dp）。底部导航普通字号下为 60 dp，较大系统字体按内容增加高度；会话顶部继续使用既有 72 dp 外层结构。
- 高密度页面通过去掉重复容器、序号装饰和多余文字释放空间。网络 IP、核验、等待应用等判断信息保留。
- 系统大字体下，Tab 可以横向滚动，选中项自动进入可见区；弹窗底部操作改为纵排，环境编辑页把主保存按钮放到第二行，避免为放下标签而把字缩小。当前入口最多三行；大字体下放到节点列表前，避免丢失当前候选的名字。

## 此轮减法

移除普通主按钮的渐变、设置行内重复描边、环境序号的蓝色胶囊、每张环境卡片的实心蓝色打开按钮、会话模式切换的外层重复描边。环境卡片“更多”改为既有菜单图标，保留完整无障碍名称；“最近使用 ·”收短为“最近”，没有使用记录时不显示空历史提示。常规字号下把环境标题、多选和新建放在同一行，只在“全部”筛选保留总数；网络筛选收进标题区。代理示例独立换行，大字体下也能读全。

## 验收

使用真正的 Android 原生组件截图，覆盖 360 × 640 dp、412 × 640 dp、系统字体 100% / 200%，这两个高度较短的测试视口覆盖会话外壳、环境列表、网络列表和关键编辑弹窗。对照版本仅将八个 UI 源文件恢复为 1.5.12 样式，两份测试 APK 使用同一份核心实现、版本号、签名和本地合成数据。没有用网页原型代替 Android 画面，也没有用本地 HTML 替换应用里的真实网页。

Oil UI 的网页截图程序不适用于 Android 原生控件，此处使用 adb/uiautomator 与原生截图。截图、评审和验证材料放在版本对应的 `verification/oil-ui-v1.5.13/` 中。评审按已有规范进行一轮，不打分；只基于看到的原生画面，不把源码编译当成视觉通过。

业务、浏览器生命周期、环境隔离、代理连接、登录数据与后台回复逻辑沿用前版。
