# 1.5.20 · GeckoView 官方网页客户端

本版按新的产品方向收拢为 GeckoView 客户端。ChatGPT 官方网页负责聊天、模型、历史和消息操作；应用只保留环境、网络、文件、阅读及可选后台检测。删除正常操作的打扰，错误留在页面内，内容丢失、删除和任务中断保留确认。

此前已确认的连接复用与探测优化继续保留。实际手机和电脑之间的延迟差距仍需同条件验证。

| 文件 | 修改与作用 |
| --- | --- |
| `NetworkPoolIdentity.java` / `ChatSession.java` / `GeckoWebView.java` | 将浏览器连接池绑定到已核验的环境、核心生命周期、入口、固定出口及手机默认网络。健康的同路线恢复不因一次新回调而换池；真实线路、核心或默认网络改变时使用新池。`connectionEpoch` 仍负责拒绝过期回调，各环境继续隔离。 |
| `NativeNetwork.java` / `LatencyProbePolicy.java` / `RouteQuality.java` | 将测量绑定到发起时的核心、路线和请求身份，拒绝过期结果；区分暖连接、重新建链和首次响应。首次与冷复测不混入暖连接排名，保留当前线路健康判断与出口核验。 |
| 网络状态与诊断 UI | 延迟对首次响应和冷复测显示“首次”“复测”，并保留真实失败类别；不把总探测耗时或失败等待冒充正常延迟。 |
| `third-party/patches/` / `tools/build-mihomo.py` / 两 ABI 的 `libmihomo.so` | 基于 Mihomo v1.19.31 的 `v1.19.31-pocket-probe1` 探测补丁：把控制请求取消传入内核；后续探测需要新连接时重新拨同一条链；复测失败返回首次有效响应耗时。提供源码补丁、固定工具链和构建 receipt。网页流量转发、代理协议和 TLS 验证保持原有实现。 |
| `MainActivity.java` / `DesignChrome.java` / `AppHub.java` / `LoadingUi.java` | 只挂载真实 Gecko 网页，移除简洁切换、自制输入与模型界面，压缩外层导航；正常操作不弹提示，故障在页面内显示。 |
| Gecko 浏览器与兼容策略 | 删除实际系统内核创建和切换路径；沿用 Gecko profile、Cookie 保存与 SDK 页面状态；旧草稿和旧系统数据保留，不自动提交旧任务。 |
| 通知、下载与设置 | 统一前台安静、后台明确开启的完成提醒；保存、复制和下载进度留在对应页面，不自动打开提示弹窗。 |
| 应用更新线路 | 更新连接绑定发起环境和核验线路；失效时停止连接并保留 Range / ETag 进度，恢复时重新取得同环境线路。 |
| `app/build.gradle` | 正式版本更新为 1.5.20 / code 46；依赖固定的 Mozilla 官方 GeckoView，移除 AndroidX WebKit 与旧简洁页面渲染资产。 |

本地对照执行了真实内核和双 SOCKS 链。200 条完整线路的应用配置与简化 Clash 等价配置对比，没有测出配置本身增加约 300 ms；HTTPS 冷连接与复用连接存在明显差距。另有 52 项原版/补丁对照，验证探测分类、重拨、RST、超时、取消和 TLS 拒绝。它们是受控回环测试，不是用户节点测速或 Android 浏览器验收。

源码 `8d314900` 已完成正式构建、14 组本地回归（464 项）及 10 组 Android 模拟器回归。86 个设备操作覆盖两个环境的登录 Cookie、草稿与重启恢复、真实图片选择及上传、TXT/CSV/Blob 文件、环境删除和旧设置兼容；另有原更新续传 28 项、选定环境更新线路 32 项、安静提醒 42 项和重新加载确认 8 项。健康恢复复用实际 HTTP/2/TLS 连接，路线改变后重新隔离；测速取消结束实际请求，保持原网络与既有 WSS。原签名、公网完整 APK、更新源和官方 CDN 的 Range / If-Range 续传均已核验一致。见[完整验证记录](../verification/chain-performance-v1.5.20/README.md)。真实账号登录与 ARM 手机长时间体验尚未验证。

原签名、包名、环境账户和网络配置保留。真实线路或保护凭据不再成立时仍拒绝联网；没有增加自动发送、自动重发或直连回退。冷测值可能明显高于暖测值，这是不同工作阶段的真实耗时。1.5.19 的 SDK 原生输入偶发光标回退尚未归因，也未因本次网络改动而宣称修复。
