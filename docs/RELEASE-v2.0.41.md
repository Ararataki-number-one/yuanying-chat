# 2.0.41（条件开发候选）

增加环境配置的加密导出与导入入口。可携带的内容严格限于环境名称、浏览器模板、语言顺序及七项布尔偏好；不包含登录、Cookie、聊天、草稿、附件、网络凭据、订阅、固定出口或来源环境身份。

文件使用带认证的加密格式；密码对话框单独设置安全窗口标记，派生密钥与文件处理在工作线程执行。导入预览确认后，仅创建新的未使用环境身份，网络保持未配置并要求外部 VPN，不打开网页或覆盖现有环境。

恢复通过归属标记及目录写入事务确认新环境。清理仅处理仍未使用、无浏览器且批次、身份及代次完全匹配的暂存记录；已创建、外来或归属未知的记录保留。提交前最终检查之后关闭界面，已提交的创建仍可能完成；提交回执不明时显示待确认，请先检查环境列表，不自动重复导入。

版本为 2.0.41 / 94，内置扩展为 2.0.41.94。本离线前缀仅继承拟定 2.0.40 树，尚无正式 2.0.40 前序提交。主机密码学与目录故障适配器检查不代表真实 Android SQLite、Keystore、文档提供者、输入法或手机验收。发布前需对齐实际前序源码，完成真实 SDK 构建及原发布门禁。当前未提交、未签名、未发布。
