# 2.0.21：网页配色确认、线路恢复与文件保存保护

versionCode 74，基于已发布的 2.0.20。保留单 GeckoView、ChatGPT 原网页、登录与草稿、环境隔离及固定出口。

- 网页配色增加当前文档与指令版本的回执，分别记录收到、设置应用、存储回读和聊天区域颜色采样。旧回执不能确认新文档；每次同步最多尝试三次。重新选择当前配色或点按“重新同步网页配色”可主动重试，检查结果可复制且不含聊天、登录或线路凭据。
- 故障恢复不再依赖已经坏掉的原入口。普通候选失败后，在原期限内继续核验其他入口；恢复期间自身选择造成的 serial 推进不会丢弃仍有效的并行探测。健康线路换优、固定出口、配置代次、控制器及期限保护继续生效。
- 下载记录提交失败时安全暂停传输，保留仍存在的部分文件及待确认状态，避免异常逃出界面回调。外部文件提供者的保存结果无法确认时保留线索；缺少查看器也不会声称文件已保存。存储始终无法写入时，不能承诺这些新状态在进程退出后可靠恢复。
- 冷 SOCKS 准备阶段的明确瞬时传输错误可在同一路由和原期限内重试一次；不扩展认证失败、协议错误、冷 CONNECT 命令失败或业务内容的重试。
- 下载索引增加三个非唯一索引；每轮列表刷新批量读取环境名称。Cookie 快照合并为一个在途及一个最新待写请求，保留恢复失败、退出登录和清除屏障的顺序保护。
- README 下载入口改为最新 Release，构建说明对齐实际派生 SDK 与当前版本来源。

过程、可复现证据和后续测量见 [体验修复记录](EXPERIENCE-RELIABILITY-20261026.md)。

正式打包前须通过当前同源码的发布检查。真实官网持续亮色的唯一原因仍未确定，需要实际设备的配色回执继续定位；合成网页及其 Gecko 桥接测试不能替代官网验收。本版没有同手机帧耗时、CPU／内存或真实代理线路提速结论。
