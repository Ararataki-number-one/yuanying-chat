# 界面与功能对应

最新结构详见 [环境管理与配置结构](ENVIRONMENT-MANAGEMENT.md)。

| 页面 | 实际功能 |
| --- | --- |
| 环境管理 | 最多 8 个环境；卡片展示名称、分组、网络状态与最近使用；打开为主要操作，其余收进更多；搜索与组合筛选；三种排序 |
| 环境多选 | 长按或多选入口；全选当前结果；保留并提示筛选外选择；批量分组、收藏、取消收藏；返回先退出多选 |
| 新建环境 | 基本信息、网络来源、确认创建；网络设置可从默认或指定环境复制；登录与聊天分别保存 |
| 环境编辑 / 基本信息 | 名称、分组与备注；草稿与应用配置分别保存 |
| 环境编辑 / 网络配置 | 显示当前配置，保存编辑草稿后进入网络流程 |
| 环境编辑 / 浏览器 | 三档保护、实际 WebView / UA / 屏幕 / 语言 / 时区、自检入口 |
| 环境编辑 / 使用偏好 | 会话恢复、后台与通知、下载与存储、临时文件清理 |
| 环境网络 | 有明确所属环境；手机网络、代理、内置订阅与固定出口；节点、出口和连接诊断按模式显示 |
| 下载中心 | 汇总各环境文件和任务；展示真实进度；按所属环境处理任务 |
| 应用设置 | 默认环境与启动入口、界面说明、系统权限、使用帮助与能力范围 |
| 会话 | 原网页与简洁模式、历史、附件、下载、发送记录；页面切换保留当前环境与网页 |

管理界面采用浅色底、白色内容卡片和蓝色重点操作。ChatGPT 原网页仍由网站绘制。`docs/screenshots/` 的旧星空截图是 1.5.0 历史资料，不代表当前管理界面。

`FutureFeatures.Adapter` 接口保留。尚未实现的自定义指纹、多订阅、自动化等能力统一在应用设置中说明。DNS / TCP / TLS 分项和完整泄漏检测仍未覆盖，不生成示例结果。
