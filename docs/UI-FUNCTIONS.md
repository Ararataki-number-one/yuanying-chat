# 产品设计图与实际实现

| 设计图部分 | 本地版本的实现 |
| --- | --- |
| 1 启动/品牌 | 蓝色传送门插画、原生品牌图标、标题、进入按钮；首次展示，后续按照启动设置路由 |
| 2 默认页/原网页 | 默认窗口可指定；应用外层深蓝工具栏、网络条、模式切换、主机名和五个导航；网页自身内容保留 |
| 3 窗口首页 | 卡片、默认与收藏标记、进程/等待/异常状态、搜索、五类筛选、打开与编辑菜单 |
| 4 创建窗口 | 三步流程，名称与平台、网络配置来源、确认；支持设为默认，最多 8 个 |
| 5 编辑/基础 | 窗口名称可修改，平台与系统信息真实只读；草稿与应用设置分别保存 |
| 6 编辑/浏览器 | 显示实际内核、UA、屏幕、字体与限制状态；三档隐私保护可选；自定义参数/扩展/脚本预留 |
| 7 下载中心 | 跨窗口文件与任务列表、实际字节进度、分类、打开/分享/另存为、跳转所属窗口处理任务 |
| 8 网络方案/订阅 | 当前窗口真实方案与单个订阅配置、更新与编辑；多个方案/订阅预留 |
| 9 入口/出口/诊断 | 当前线路测量、节点操作、实际核实的出口、连接链路与现有耗时诊断；没有测量的数据明确标为未覆盖/开发中 |
| 10 设置 | 当前窗口与全局分层，含基础、浏览器、网络、数据、偏好、默认入口、外观、下载、后台与关于 |
| 11 隐私/自检 | 三档保护、当前实际能力摘要、原有一致性与出口检查、基线变更与检测范围说明 |

## 接入约定

`FutureFeatures.Feature` 定义预留项目，`FutureFeatures.Adapter` 提供 `available(feature)` 与 `open(activity, feature, slot)`。以后接入后端时，可以通过 `register(adapter)` 实现对应入口。当前未注册适配器，入口只有开发状态说明。

网络、隐私、上传下载、回复状态与登录逻辑沿用现有实现。新页面消费已有状态；没有结果的 DNS/TCP/TLS 分项、完整泄漏检测和地区核验不生成示例成功数据。

`AppSettings` 只保存全局 UI 选项，放在共享窗口目录的新增表中。窗口网络与账号配置继续保存在各自环境。下载跨窗口索引只存文件/任务展示元数据。

## 视觉范围

应用原生界面采用设计图的深蓝、青色边框与蓝紫渐变。ChatGPT 原网页仍由网站绘制，不静态替换成设计图里的示例内容。图中的旧域名示例以实际访问的主机名显示。

本地界面预览覆盖品牌、窗口、创建、聊天外层、编辑、下载、网络、分层设置和隐私页面。测试网页只用于验证行为，因此预览中的网页文字不代表真实账号内容。
