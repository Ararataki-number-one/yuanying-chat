# 本轮界面与功能对应

| 你的要求 | 1.4.1 的实现 |
| --- | --- |
| 不要记录页面 | 删除独立页面与底部记录入口，聊天里的会话历史继续保留 |
| 刚进入先显示窗口 | 应用图标进入原生窗口首页，不自动打开聊天网页 |
| 点窗口再进入 | 整张卡片可点击，进入该窗口的原有独立进程和登录目录 |
| 类似参考图的窗口列表 | 深蓝卡片、蓝紫渐变创建按钮、数量、搜索、收藏、已打开筛选与窗口操作菜单 |
| 默认下载位置 | 安卓 10+：`Download/元婴期院士/窗口_编号/`；安卓 8–9：各窗口应用内文件目录 |
| 后面在下载页找到 | 首页下载入口显示所有窗口的已保存文件，聊天下载入口保留当前下载任务与继续操作 |
| 已有功能保留 | 原历史管理、后台等待、通知、附件、网络及隐私保护保持可用 |
| 已有窗口数据保留 | 不改变原 Activity、进程、WebView 目录、登录记录与加密配置名称；目录表增加收藏和上次打开字段 |

窗口首页只展示真实保存的窗口与状态。参考图中的国家、城市和账号已绑定徽标需要真实核验数据，本轮不会预填示例事实。尚未要求的清理账号数据和删除窗口操作未加入菜单。

下载目录使用稳定窗口编号，不会因重命名窗口而移动文件。列表通过本地 SQLite 文件索引跨窗口更新，索引只包含文件名、位置、URI、时间等文件元数据，不包含登录 Cookie、聊天内容或临时下载源链接。

源码包包含真实竖屏界面截图、测试脚本与逐项结果；截图中的窗口名和文件来自独立测试数据。
