# 1.5.8 手机阅读与浏览器运行优化

电脑版保留 Firefox 桌面浏览器身份，按手机宽度排版，取消把整张 1024px 桌面页面缩进屏幕的默认显示。响应式网站自行折叠侧栏，让正文和原输入框可读、可用；不重新实现 ChatGPT 页面。最终布局由真实网站决定，不能保证与参考截图的每个按钮一致。

阅读缩放在各环境单独保存。旧缩放按实际屏幕尺寸换算一次，原值继续保留。首次加载和旋转等待内核报告实际视口，避免用猜测尺寸再次缩小页面。

浏览器会话被关闭后，重新加载重新打开同一环境的浏览器目录。子窗口关闭后恢复父窗口返回历史。旧网页断开只能结束自己的请求，完成的请求立即移除超时任务。内核失败时暂停网页轮询，保留原发送记录，避免故障提示被覆盖成“等待回复”。

## 修改文件与原因

| 文件 | 修改与目的 |
| --- | --- |
| `GeckoWebView.java` | 分别配置桌面身份与手机视口；按窗口保存 URL、返回历史、尺度和视口；完善父子窗口切换、关闭和会话恢复；请求与当前连接绑定；主动停止旧加载后忽略晚到的停止结果。 |
| `BrowserBridgeRequests.java` | 统一 JavaScript / Cookie 请求的完成、超时和取消；按确切连接处理结果，避免旧连接干扰新网页，完成后清理计时任务。 |
| `assets/gecko/content.js` | 只读报告真实页面视口和缩放，随布局变化更新；不改官网标题、模型选择器、消息或输入框。 |
| `BrowserReading.java`、`BrowserReadingPolicy.java` | 根据实际视口计算阅读尺度；等待内核测量；兼容旧缩放，并保留各环境的缩放记忆、手势与键盘处理。 |
| `BrowserPrivacy.java` | 系统内核兼容分支取消桌面视口注入与整页缩小；保留桌面 UA、现有隐私与网络保护。 |
| `BrowserReadingUi.java`、`EnvironmentEditorUi.java` | 缩放和电脑版显示提示改为人能理解的说明；不增加会话顶部元素。 |
| `ChatSession.java` | 内核失败时暂停网页状态轮询，故障提示和原发送记录保留。 |
| `app/build.gradle`、`AndroidManifest.xml`、`assets/gecko/manifest.json` | 更新到 1.5.8 / versionCode 34；内置桥接扩展随正式包更新。 |
| `tests/browser-runtime/`、`tests/browser-reading-host/` | 生产请求管理器和阅读控制器的 JVM 回归，覆盖旧连接、连续操作、旧缩放转换、手势、横竖屏宽度及键盘处理。 |
| `tests/gecko/` | Android 原生双环境、可信触摸弹窗、会话关闭 / 恢复、慢资源、停止加载和不同屏幕宽度的受控回归，并保存实际渲染截图。首次绘制可能仅为背景；取消测试先确认当前文档和正文已就绪。 |
| `tests/BrowserReadingRegressionActivity.java` | 旧系统内核样本显式选择系统内核，适应现有 FrameLayout 接口。 |
| 工作流与发布脚本 | 自动执行回归、记录准确源码与 APK 哈希；按当前版本验证原证书、包名、非调试状态、无测试入口及对齐后发布。 |
| `docs/BROWSER-EXPERIENCE-BENCHMARK.md`、`docs/BUILD.md` | 记录 AdsPower 公开工作流参照、最新截图目标、构建方式和验证边界。 |

## 验证边界

完整编译、56 项 JVM 检查、29 次 Android 原生受控操作和原签名检查均通过，结果见 [本版验证目录](../verification/browser-experience-v1.5.8/README.md)。响应式截图来自明确标注的受控样本，不是成功访问官方 ChatGPT 的截图。Google / ChatGPT 真账号、ARM 真机、实际系统低内存回收、真实订阅完整线路及键盘长时间输入仍需设备验收。

沿用原环境数据、网络配置、下载和后台回复服务。插件和网络新功能继续暂停。重新打开已关闭的网页会话需要重新加载，不能承诺恢复原文档返回栈和网页中未持久化的表单。Firefox 与系统内核仍分别保存登录。
