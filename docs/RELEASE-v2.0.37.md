# 2.0.37（条件开发候选）

附件准备沿用已有复制流程，在提供者调用返回后检查原有取消状态，避免继续读取后续数据块或文件。仅提前清理尚未交给网页的附件副本；清理结果记录失败项，已交付及来源不明的缓存继续保留。

存储详情使用已有附件工作线程，按用户操作进行一次有条目及协作时间上限的只读采样。显示结果及原有下载清理操作前，核对 Activity、环境、代次及浏览器归属；关闭界面不让排队任务直接持有界面引用。采样量不代表可安全删除的容量。

阻塞中的提供者及文件系统调用必须先返回，取消与采样预算才能继续生效。主机上的读取字节对比不代表手机延迟或整体性能。没有增加轮询、执行器、权限或自动回收已交付附件。

版本为 2.0.37 / 90，内置扩展为 2.0.37.90。本离线前缀继承拟定 2.0.36 树，保留 2.0.32 的原生权限拒绝处理；尚无正式 2.0.36 前序提交。发布前需对齐正式前序源码，完成本版实际 SDK 构建及原发布门禁。真实 Android／Gecko 文件选择取消、存储界面与手机场景仍未验收。当前未提交、未签名、未发布。
