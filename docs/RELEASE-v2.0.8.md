# 2.0.8：代码整理、输入同步与下载列表优化

- 合并环境身份、订阅快照和更新校验中的五处重复哈希实现，保留原有配置身份和校验结果。
- 入口与出口共用快照写入流程，每份订阅数据的完整哈希由四次减少到一次；文件锁、失败回退和已有登录数据保留。
- 下载列表减少排序期间的重复读取与临时对象，继续保持正在下载优先、完成文件按时间排序。
- 环境节点池改用集合去重，避免节点较多时反复扫描列表；排序和最终配置身份不变。
- 修复输入回执处理时过早清空队列的竞争窗口，避免尚未处理完的组合输入被提前同步；中文输入仍须完成 Android 回归验证。

保持单 GeckoView、ChatGPT 原网页、独立环境、网络分享、日夜模式与问题反馈功能。

云端局部基准中，1000 条文件加 250 条任务的排序由约 3.19 ms 降至 0.86 ms；1 MiB 订阅快照的普通文件测试保存由约 14.26 ms 降至 7.16 ms。这些是局部计算与 host 文件夹具的结果，不代表整机提速比例或公网延迟。

构建及 Android 回归由本版发布流水线执行并核验。ARM 真机、真实 ChatGPT 账号和用户公网延迟没有新增验收结果。
