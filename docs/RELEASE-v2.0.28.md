# 2.0.28：本地对照的人工检查进度（发布候选）

2.0.25 已有两份独立本地报告和人工结果。本版复用其格式、加密保存及主动操作流程。

- 显示已记录、未测试、异常与不适用项目；进度表示记录情况，不是保护得分。
- 人工结果菜单显示每项当前值，编辑时预选已有值；没有操作的项目仍为未测试。
- 原有记录时间保留在结构化检查清单中。替换报告仍重置该报告的人工结果。
- 不自动切换模板、导航、发起检测、修改登录或声称真实手机已通过。

本版单独补齐人工检查进度的边界回归，并沿用原双报告测试；无需等待 2.0.29 才验证。打开人工菜单合并对同一报告的重复恢复，点击项目时仍读取最新状态。

本次仅推进 2.0.28，不包含 2.0.29—2.0.30 的参照总览或模板能力评估。主机检查和受控 Android／Gecko CI 分别记录；真实手机操作与保护效果仍待设备验收。
