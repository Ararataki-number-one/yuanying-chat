# 1.5.1 环境管理优化

应用版本 1.5.1，versionCode 27，使用原版签名。

- 环境卡片集中显示名称、分组、网络状态和最近使用时间。“打开环境”为主要操作，编辑与配置收进“更多”。
- 新增长按与多选入口、全选当前结果、批量分组、批量收藏和取消收藏。
- 筛选后保留选择，明确提示筛选外的环境数量；返回先退出多选。选择以稳定环境编号保存，不依赖排序位置。
- 批量分组可使用已有分组或新分组，留空回到未分组。批量数据库写入使用事务，不覆盖备注、草稿和网络配置。
- 新增原版与上一轮预览包的覆盖更新回归工具，检查样本 Cookie、会话草稿、加密记录和文件保留。工具限定在一次性模拟器使用。

本轮运行结果单独保存在 `verification/environment-management-round2/`。模拟器回归和真机登录保持分别记录，不将样本 Cookie 当作真实账号登录验证。
