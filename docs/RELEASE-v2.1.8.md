# PocketChat 2.1.8（110）候选更新

状态：开发与验收中，尚未发布。以正式 2.1.7 源码 5bf46502 为基准。

- 下载：HTTP 最终响应、Gecko 原生响应和 Blob 均更新文档 MIME 信息，不再仅更新图片；保留已知文件名，并采用有效的最终下载响应文件名。
- Gecko 新窗口：允许与当前公共网页同来源的 Blob 新窗口；早于窗口激活返回的下载响应排队交接，交接时重新核验当前页面、网络保护与销毁状态，失效响应关闭流，不强行切回后台窗口。
- 浏览器模式：不再创建或恢复网页发送确认任务，移除后台回复检测设置；历史记录与草稿仍保留。网页资源/上传保护和下载完成提醒继续保留。
- 顶部：足够宽的单行网络状态使用更紧凑布局，并为环境胶囊与网络详情保留独立 48dp 触摸区域；窄屏和大字号继续使用完整行高。五个底部入口与玻璃风格保持。

## 验证边界

主机回归检查不等于真实网站下载、实体手机或账号验证。新窗口下载与紧凑布局必须通过当前源码的完整 Android 验收后方可发布。不得使用 2.1.7 的旧验收结果替代本版结果。保留失败运行，不跳过检查，不降低断言或延长期限。
