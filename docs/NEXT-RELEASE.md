# 下一正式版待发布改动

## 2026-10-16：移除对话变化提示

用户要求不再显示截图中的“对话已改变，请检查上次发送；不会自动重发”。

已在聊天界面状态展示处静默处理这条消息：不再显示顶部红色提示，也不在其他页面弹出对应反馈。真实网络状态仍常显，发送记录与不自动重发的行为保持原样。

状态：已随 2.0.4 正式版发布，构建、lint 和 Android 回归通过；验证了该提示隐藏且不占位，以及真实发送失败提示仍可见。ARM 真机尚未验收，详见 [2.0.4 验证记录](VALIDATION-v2.0.4.md)。

## 2026-10-16：出口密码与网络分享

出口新增/编辑表单及原高级配置入口默认明文显示密码；输入框内提供“隐藏/显示”，不新增一行。切换显示保留文本和光标，本机加密保存方式不变。已随 2.0.4 正式版发布；Android 表单验证覆盖 360dp 宽度下的正常及放大字体，实际点击验证默认显示、隐藏和恢复显示。

入口、出口和整条线路分享已随 2.0.5 正式版发布：入口节点、固定出口及窗口网络卡片的“更多”菜单分别提供分享；网络页“更多 → 导入网络”支持文件或粘贴，先预览，再选择已有环境并显式应用。见 [实际发布范围](RELEASE-v2.0.5.md) 和 [验证记录](VALIDATION-v2.0.5.md)。

已实现默认跟随系统的外观切换和手动白天／黑夜；网页沿用官方主题，切换不刷新会话。网络改动集中在有限候选探索、快节点复核、网站探测预算和取消无助于出口解析的例行 DNS 轮测。详见 [2.0.6 改动](RELEASE-v2.0.6.md)。状态：已随 2.0.6 正式版发布，构建、lint、Android 回归与公网下载校验通过。尚无用户线路 200 ms 公网结果，见 [验证记录](VALIDATION-v2.0.6.md)。
