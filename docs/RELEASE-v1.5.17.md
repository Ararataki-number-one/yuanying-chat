# 1.5.17

- 减少聊天页滚动、输入和长回复生成时的后台开销：生成期间只检测真实状态与内容版本，结束后完整采集回复；正文未变化时复用已确认内容。
- 顶部、网络信息与模式按钮按变化更新，合并同一轮中的重复刷新，减少无意义的文字测量和背景重建。
- 将周期性环境心跳、加密配置核对和网络元数据读取移到后台；地区与延迟缓存按环境隔离，避免多个环境交替刷新时重复解密。
- 背景绘制不再逐帧查询数据库或创建绘图对象；保留原页面外观和紧凑顶部。

保留真实网页登录、环境隔离、网络保护、附件和下载流程，以及原来的稳定完成判断与完成提醒。本版继续使用原签名，支持覆盖安装和应用内更新。

通过受控 Android / Gecko 的长会话、终态完整性、输入草稿、存储隔离、网络与通知回归后发布。性能比较针对后台检测的读取和传输工作量，不能等同于真机帧率；用户手机上的具体异常仍需要复现确认。
