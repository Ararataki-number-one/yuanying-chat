# PocketChat 1.7.0 候选

以 1.6 网络与环境底座为基础，保留下载文件/安装包删除、独立环境、单官方 GeckoView 和 ChatGPT 原网页。

- 增加标准与兼容模式的移动/桌面模板；已有强化配置继续保留为实验模式。
- 分别记录期望请求、SDK 接受与实际网页观测；SDK getter 不代表网页指纹已经生效。
- 请求语言和 Firefox 的 language-region 规范化预测分别保存；页面、iframe、Dedicated Worker 和请求头单独核对。
- 电脑版保持原有显示；部分 Worker 联网请求使用 SDK 的手机版 UA。自检区分 JS 字段与 HTTP 请求头，本版不承诺完整桌面指纹一致。
- 模板修改复用既有安全延后应用；排队失败时保留已应用配置、保留期望编辑并说明重试方法。
- 自检缺少字段或类型错误时标为未覆盖，保留实际差异。
- 正常设置操作保持安静，模板保存不改环境名字、其他偏好或编辑草稿。
- 模板页直接显示期望模板、浏览器已接受的设置和最近自检；版本号及能力限制放在中央详情弹窗中按需查看。
- 环境列表增加“复制环境配置”：复制浏览器模板、网络和使用偏好，新副本使用独立身份，不复制账号、聊天或草稿。创建向导的“使用另一环境网络”仍只借用网络。
- 增加明确确认后的“重置登录数据”：保留环境名称、逻辑身份、模板、网络、密钥与已保存下载；清理目标 Gecko 登录/站点数据、恢复检查点、本地草稿和聊天缓存，并中断其进行中的任务。
- 重置持久记录维护状态、推进环境代际并退役旧应用/观测回执。未完成时从环境列表继续重试；旧确认、旧配置回调、旧心跳和槽位复用不能越过相应身份检查。

候选源码继承 1.6 的网络恢复、双订阅和真实 SDK 请求头范围修正。发布验证须使用当前完整源码的官方 Gradle/Android 回归、独立 190 项受控模板观测门禁（原 181 项加真实关闭网络保护后的 9 项检查），以及扩展的配置复制、登录重置与槽位复用检查；未经当前源码的实际通过结果，不视为发布验收。

HTTP 观测按实际支持范围分角色核对：文档等请求采用会话 UA，Worker fetch 采用独立 SDK 默认 UA，并保留桌面差异。输入性能仍使用未放宽的既有基线；未声称相关卡顿已修复。受控页面、合成 Cookie 和模拟器检查不代表真实 ChatGPT、ARM 手机、百度输入法、持续使用或实验强化模式已经通过。真机步骤见 [PHONE-ACCEPTANCE-v1.7.md](PHONE-ACCEPTANCE-v1.7.md)；正式发布仍需使用者提供绑定候选安装包的验收结果。

当前回归复现过原生输入光标短暂回退，导致已到达网页的字符顺序改变。仍在独立诊断中；后续单次输入检查通过不能作为该问题已修复的证据。百度输入法的候选词、光标移动及连续输入必须继续按真机清单验证。

没有独立时区、Canvas/WebGL/音频/字体伪装承诺。跨源 iframe、Shared Worker 和 Service Worker 的自检覆盖仍未提供。
