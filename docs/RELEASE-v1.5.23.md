# 1.5.23

- 网络页分为“窗口网络 / 入口 / 出口”。入口、出口订阅独立管理，支持添加、编辑、更新、删除以及查看更新失败原因；保留已有手动 SOCKS5 出口。
- 每个环境显示“入口节点 → 固定出口”，新环境默认自动优选入口，出口按环境固定。旧环境继续使用原来的选择方式。
- 订阅刷新按节点连接配置保留有效选择，支持节点改名；节点失效、同名换配置或别名不明确时要求重新选择。
- 编辑只形成候选配置，保存后在安全空闲时应用。开始新回复、上传、下载或切换页面时，保留候选及原连接；取消选择不会改变当前环境。
- 两边订阅使用各自的加密快照。复制环境时同时复制有效的入口、出口配置，不复制登录、聊天草稿或尚未应用的操作。
- 修正电脑版网页异常放大和横向裁切，“适应屏幕”使用 Gecko 原生比例恢复宽度及横向位置，保留纵向阅读位置、登录和草稿。

版本为 1.5.23 / code 49，沿用原包名与原签名。浏览器保持官方 GeckoView 157.0.1 和 ChatGPT 原网页。固定出口订阅目前支持 SOCKS5。

本轮受控测试验证订阅管理、环境隔离、链式连接和数据保留；真实节点的速度及延迟需要在相同设备、链路和检测地址下测量。具体 Android 验证结果将在当前源码回归完成后补齐。
