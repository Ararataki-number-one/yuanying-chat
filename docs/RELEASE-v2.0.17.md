# 2.0.17：线路分享与设置应用

候选版本，第二批修复正在集成，完整 Android 验证及正式发布尚未完成。

- 按原生核心接受的字段、类型和别名整理节点导出，改善整条线路分享的兼容性。未知外部依赖仍须说明，导出前继续核对原生节点指纹。
- 为订阅中的可分享节点保存加密候选索引，并绑定源文件摘要、节点指纹和版本。索引缺失或失效时回到原解析流程；索引不能代替最终原生核验。
- 修复大整数经过 Android JSON 缓存或分享导入后丢失精度，以及浮点数密码文本转换与原生核心不一致的问题；同时覆盖插件参数内的超大整数。
- 普通分享继续使用兼容格式。需要保留特殊数值的分享使用新版格式，并提示接收方需要 2.0.17 或更新版本；旧版会要求更新，避免静默改变参数。新版继续接受旧版分享。
- 复杂节点解析失败也计入订阅的累计解析预算，避免连续失败节点绕过工作量上限。
- 待应用设置重试复用原候选，不重复创建任务；使用有上限的退避，并在网页真正恢复可操作时唤醒。完成任务的迟到回调不能重新生成已清理记录。
- 设置保存、等待应用和当前实际运行配置分别显示。实际应用须匹配环境、候选、配置版本、网页策略和当前连接回执；核心已启动不能单独代表网页配置已生效。
- 统一“自动优选”的名称，操作结果留在当前面板中，维持原有网页、草稿和附件保护。

本版对应问题计划中的 S01–S07、A01–A02。原网页、多环境隔离、固定出口和接收端预览继续保留。分享不包含网页登录或聊天内容。

主机、受控原生连接和 Android 测试分别记录验收范围；它们不能替代用户线路、真实 ChatGPT、ARM 真机或百度输入法验证。性能优化将在后续按固定流程重新测量，本版没有新的提速结论。
