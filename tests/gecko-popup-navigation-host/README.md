# Blocked popup current-page workflow host

This JDK workload executes the complete current `GeckoPopupNavigationUi` source,
plus extracted unchanged `GeckoTimeZoneUi.Fence` and busy checks, draft completeness,
draft policy, exact ChatGPT predicate and environment identity. Shared public URL,
diagnostic URL, task snapshot and browser settings policies compile unchanged.

Android widgets, lifecycle delivery, native SDK identities, archive writer lease,
driver results and final browse are explicit named boundaries. No `org.mozilla`
stub packages are created. The workload proves callback/fence/input decisions;
it does not prove native rendering, Android focus delivery, SQLite or Gecko loads.
Actual Android/SDK compilation and integration remain independently required.

```sh
python3 tests/gecko-popup-navigation-host/run.py --java-home "$JAVA_HOME" \
  --json-jar path/to/actual-json.jar --output work/popup-host/result.json
```

Run with both supported real JSON jars. Every mutation compiles separately,
requires its pristine focused assertion to pass, then must fail that unchanged
assertion. Prior tests, popup rejection assertions and time budgets are untouched.
The native offer is one button per document, latest target while that action
exists; focus invalidation suppresses new unsolicited offers in the same document.
