controllers, stores, specs and profile reconciliation plus actual ProfileContext and

Android, Gecko, SQLite, Keystore, native preferences or browser login execution.

actual runtime-profile assertions, independently of the source metadata pins.

single-file legacy layout. The factored branch never supplies a predecessor image
to member extraction or javac. The active `GeckoRuntime.create` block and actual

disconnected runtime arguments, an unused correct builder, a comment decoy, and

keeps all twelve canonical jobs and its unchanged device workload budgets.
