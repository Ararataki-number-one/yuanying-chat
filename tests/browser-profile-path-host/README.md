This helper is invoked by the existing BrowserRuntimePolicyTest CLI. Its stdout is
one fixed protocol token; complete local diagnostics go to the separate JSON report.
It binds the known active source layout, then compiles raw current CPU/TLS
controllers, stores, specs and profile reconciliation plus actual ProfileContext and
Profiles directory methods and the complete active GeckoRuntime.create statement.
Real temporary files, locks and atomic moves preserve opaque cookie/draft sentinels.
Android Context/process, catalogue, plaintext test vault, queues, and SDK settings /
create are explicit boundaries. Capturing the actual create argument does not claim
Android, Gecko, SQLite, Keystore, native preferences or browser login execution.
Current Java never uses historical source views. Compiled wrong bindings must fail
actual runtime-profile assertions, independently of the source metadata pins.
