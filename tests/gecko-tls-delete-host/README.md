The actual pre-TLS source is compiled and must fail the new TLS assertions; five separately compiled semantic counterfeits must also fail. Root/identity/writer-exit order is checked separately, and the original 39 lifecycle controls run unchanged on each configured JSON library.

This is a filesystem/source-boundary check, not Android/Keystore/native TLS or publication qualification.
